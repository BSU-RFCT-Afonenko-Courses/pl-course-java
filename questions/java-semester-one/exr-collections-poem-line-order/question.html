Сложность: Начальный

Поместите строки короткого стихотворения из общественного достояния в список; укажите автора, название и источник. Отсортируйте копию списка по возрастанию длины строки в единицах char. Исходный порядок сохраните отдельно для сравнения. При равной длине сохраняется взаимный порядок исходных вхождений; повторяющиеся строки остаются в результате столько же раз.

Все строки отличны от null; пустые строки допустимы. Алгоритм должен работать также для пустого списка. Покажите исходную и полученную последовательности.

Предъявите выбранный текст с автором, названием и источником, исходный список и результат. Объясните получение копии и сохранение порядка строк одинаковой длины.

Вход для проверки

Вход стартера принимает список строк и возвращает его устойчиво упорядоченную по длине копию. Отдельный вход предоставляет строки выбранного вами стихотворения для той же операции; это ваши исходные данные, без готового упорядочения. Выбор произведения, указание автора, названия и источника сохраняются. Сигнатуры входа из стартера обязательны.

Открытые примеры

Равные длины и устойчивый порядок. Передайте строки в таком исходном порядке:

  1. «Всё ходит по цепи кругом;»
  2. «Златая цепь на дубе том:»
  3. «У лукоморья дуб зелёный;»
  4. «И днём и ночью кот учёный»

В результирующей копии строки идут по исходным позициям 2, 3, 1, 4; вход сохраняется. Этот опубликованный фрагмент А. С. Пушкина не ограничивает выбор собственного текста для демонстрации.

Пустой список строк. Для пустого списка результат также пуст, исходный список сохраняется.

Сдайте Study.java без объявления пакета, сохранив объявления входа из стартера.
