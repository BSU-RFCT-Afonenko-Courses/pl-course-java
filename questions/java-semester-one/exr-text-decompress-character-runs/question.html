Сложность: Высокий

Распакуйте строку, полученную по правилу Упражнение 15.5. Это корректная запись серий латинских букв A–Z/a–z; исходная строка не равна null.

Буква без числа обозначает одно вхождение. Все следующие за ней цифры до следующей буквы образуют десятичное число повторений не менее двух, без ведущих нулей. Регистр букв сохраняется; счётчик может быть многозначным. Примеры:

Сжатая запись Результат
a12b aaaaaaaaaaaab
hel2owo4rld hellowoooorld
Z Z
a2B3c aaBBBc
пустая строка пустая строка

У a12b число повторений содержит две цифры, а последняя буква b не сопровождается числом. Пустая строка остаётся пустой. Распознавать и исправлять повреждённую запись не требуется.

Представьте исходники и команду запуска. Покажите одиночную букву, многозначный счётчик, сохранение регистра и пустой вход. Объясните границу счётчика и обработку последней серии.

Сохраните обязательные имя класса и сигнатуру операции из канонического стартера и реализуйте её для переданных данных. Алгоритм, вспомогательные методы и классы, форму main, способ задания данных и оформление демонстрации выберите самостоятельно.

Единственный файл решения — Study.java из src/main/java, без объявления пакета. Вспомогательные классы, методы и демонстрацию можно разместить в нём.

Открытые примеры

Вызов Study.decompress("a2B3c") возвращает "aaBBBc": регистр сохранён, последняя буква одиночная.

Для "a12b" возвращаются двенадцать букв a и затем b — "aaaaaaaaaaaab". Для пустой сжатой записи возвращается пустая строка.
