Сложность: Средний

Это один из двух вариантов обязательного выбора: выполните эту задачу либо «Отбор книг».

Создайте класс Car со свойствами: id, марка, модель, год выпуска, цвет, цена, регистрационный номер. Поля закрытые. Предусмотрите два конструктора с разными наборами параметров, методы чтения и изменения свойств и toString(). Отбор оформите отдельными методами для массива объектов.

В исходных данных id — положительное целое; год выпуска и текущий год принадлежат 1..9999, год выпуска не больше текущего. Цена и её порог — конечные неотрицательные числа, строковые свойства непустые; n — целое в диапазоне 0..9999. Наборы параметров конструкторов выберите самостоятельно; оба способа создания должны давать такую запись. Проверять неверные исходные данные не требуется.

Создайте массив объектов и выведите:

  • автомобили заданной марки;
  • автомобили заданной модели, которые эксплуатируются больше n лет;
  • автомобили заданного года выпуска, цена которых больше указанной.

Строковые критерии сравнивайте целиком с учётом регистра. Текущий год задайте параметром; возраст равен разности текущего года и года выпуска. «Больше» означает строгое неравенство: возраст ровно n и цена ровно границе не подходят соответствующему отбору. Порядок каждой подборки совпадает с исходным массивом.

Массив может быть пустым; он, его элементы и текстовые значения не равны null. Отбор сохраняет исходный массив и объекты. Каждое подходящее вхождение остаётся в результате, даже если один объект встречается в массиве несколько раз. В подборке допустимы исходные объекты или равнозначные копии с сохранением свойств, порядка и кратности записей.

Имена методов отбора, тип возвращаемой подборки и оформление вывода выбирайте самостоятельно. Результат должен позволять различить записи и проверить их порядок. Для пустой подборки достаточно явного сообщения об отсутствии совпадений; его текст свободен.

Предъявите исходники и консольную демонстрацию трёх видов отбора. Покажите два подходящих автомобиля и отсутствие совпадений, исключение возраста ровно n и цены ровно границе, а также сохранность исходных данных. Имена остальных методов и способ запуска демонстрации выбирайте самостоятельно.

Вход для проверки

Собственную модель Car, её закрытые поля, два разных конструктора, методы доступа/изменения, toString и отдельные методы трёх отборов создайте сами. Входы стартера дают проверке возможность создать ваши реальные автомобили, наблюдать свойства и вызвать отборы. Они не задают внутренние имена полей, сигнатуры двух конструкторов или формат возвращаемой вашим методом подборки. Фасад передаёт реальный массив решения; подготовленная копия не должна скрывать изменение исходника. Сохраните обязательные объявления входа из стартера; внутреннее устройство решения и формат демонстрации выбирайте самостоятельно в пределах условия.

Единственный файл решения — Study.java из src/main/java, без объявления пакета. Предметные и вспомогательные классы можно определить в нём как вложенные или неоткрытые классы верхнего уровня. Методы и реализацию выбирайте самостоятельно; демонстрацию также можно разместить в этом файле.

Открытые примеры

Три отбора с повторными вхождениями. Возьмите автомобили:

  • C1: id 1, марка «Вектор», модель M1, год 2010, цвет «Синий», цена 10, регистрационный номер A1;
  • C2: id 2, марка «Вектор», модель M1, год 2012, цвет «Синий», цена 20, номер A2;
  • C3: id 3, марка «Линия», модель M2, год 2020, цвет «Синий», цена 30, номер A3.

В массиве [C1, C2, C1, C3] при текущем годе 2025 отбор марки «Вектор» даёт [C1, C2, C1]. Отбор модели M1 с возрастом строго больше 5 лет даёт ту же подборку. Отбор машин 2010 года с ценой строго больше 5 даёт [C1, C1]. После каждого вызова сохраняются ячейки исходного массива и все свойства автомобилей.

Возраст и цена на границе. У C4 id 4, марка «Вектор», модель M1, год 2020, цвет «Синий», цена 10, номер A4. Для массива [C4] и текущего года 2025 каждый из трёх отборов даёт пустую подборку: марка вектор отличается регистром, возраст ровно 5 не больше 5, цена ровно 10 не больше 10 при отборе 2020 года. Входные данные сохраняются.
