Сложность: Начальный

Создайте класс Test с полем int a и конструктором Test(int i), присваивающим полю a значение i. Метод void swap(Test first, Test second) меняет местами значения полей двух ненулевых объектов. Метод может быть статическим или экземплярным при сохранении указанных параметров.

Для разных объектов со значениями 3 и 8 результат — 8 и 3. Ссылки вызывающего кода указывают на прежние объекты. При вызове swap(x, x) значение x.a сохраняется. Вспомогательные переменные и доступ к полям выбирайте самостоятельно.

Предъявите исходники и консольную демонстрацию обмена двух объектов и самопередачи. Покажите значения через прежние ссылки и объясните, почему перестановка локальных параметров сама по себе не меняет содержимое объектов. Остальные имена и способ запуска демонстрации выбирайте самостоятельно.

Вход для проверки

Сохраняются Test, поле int a, конструктор Test(int) и swap(Test,Test). Технический вход стартера создаёт эти объекты, читает их текущее a и вызывает обмен. Наблюдаются прежние объекты; имена дополнительных getters и static/instance вариант не назначаются. Сохраните обязательные объявления входа из стартера; внутреннее устройство решения и формат демонстрации выбирайте самостоятельно в пределах условия.

Для сдачи используйте файлы Study.java и Test.java из src/main/java стартового проекта. Разместите их в двух редакторах без объявления пакета. Вспомогательные классы и методы можно определить в этих файлах; демонстрацию можно разместить в одном из них, без третьего исходника.

Открытые примеры

Два разных объекта. Создайте Test(3) и Test(8) и вызовите swap(x, y). Через прежние ссылки читаются значения 8 и 3.

Две ссылки на один объект. После swap(x, x) для объекта Test(-2) его значение остаётся -2.
