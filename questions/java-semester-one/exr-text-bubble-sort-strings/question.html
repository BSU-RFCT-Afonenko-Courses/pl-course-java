Сложность: Средний

Реализуйте пузырьковую сортировку массива строк: последовательно сравнивайте соседние элементы и переставляйте их, пока массив не упорядочен. Используйте естественный порядок String.compareTo. Порядок определяется знаком результата сравнения; регистр учитывается.

Массив изменяется на месте. Его элементы не равны null; строки соответствуют общим допустимым данным Данные и границы текста.

Покажите вход {"beta", "alpha", "beta", "Gamma"}, пустой массив и уже отсортированный массив. Покажите их состояние после сортировки. Объясните сравнение соседей, условие обмена и изменение исходного массива.

Сохраните обязательные имя класса и сигнатуру операции из канонического стартера и реализуйте её для переданных данных. Направление пузырьковых проходов, вспомогательные методы и классы, форму main, способ задания данных и оформление демонстрации выберите самостоятельно.

Если карточка не задаёт более узкий алфавит, входные строки состоят из латинских букв A–Z/a–z, русских букв А–Я/а–я с Ё/ё, цифр 0–9, знаков препинания ASCII, пробелов, табуляций и переводов строки. Составные сочетания Unicode не допускаются. Строки не равны null; пустая строка допустима. Символ и единица длины здесь — один char.

Единственный файл решения — Study.java из src/main/java, без объявления пакета. Вспомогательные классы, методы и демонстрацию можно разместить в нём.

Открытые примеры

После вызова Study.sort для {"beta", "alpha", "beta", "Gamma"} тот же массив содержит {"Gamma", "alpha", "beta", "beta"}: регистр влияет на естественный порядок, оба вхождения beta сохраняются.

Пустой массив остаётся тем же пустым массивом. Уже упорядоченный {"Gamma", "alpha", "beta", "beta"} сохраняет последовательность; число сравнений и идентичность равных строк не фиксируются.
