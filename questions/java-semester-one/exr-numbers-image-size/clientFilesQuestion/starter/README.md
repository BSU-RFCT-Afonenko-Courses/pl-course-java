Изображение имеет `width` столбцов и `height` строк пикселей. Каждый пиксель занимает `bytesPerPixel` байт; сжатие и служебные заголовки отсутствуют. Вычислите точное количество байтов и размер в мебибайтах: 1 МиБ = 1 048 576 байт.

Стандартный ввод содержит три целых числа `width height bytesPerPixel`, разделённых пробельными символами. Ширина и высота находятся в диапазоне от 1 до 100 000, число байтов на пиксель — от 1 до 8. Вход заведомо соответствует этим условиям.

Выведите количество байтов как целое число, затем размер в МиБ как вещественное число с точкой. Числа разделите пробельными символами, подписи и приглашения к вводу не печатайте. Для размера в МиБ допустима абсолютная ошибка `1e-8`; количество знаков после точки не фиксируется.

Ввод `1024 1024 4` даёт `4194304 4.0`; `50000 50000 3` — `7500000000 7152.557373046875`. Выберите типы промежуточных вычислений так, чтобы количество байтов оставалось точным для всех допустимых входных значений.
