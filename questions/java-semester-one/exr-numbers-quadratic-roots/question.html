Сложность: Средний

Найдите действительные корни квадратного уравнения ax2+bx+c=0ax^2 + bx + c = 0. Передайте коэффициенты a, b, c тремя аргументами командной строки. Это целые числа от -10000 до 10000 включительно, причём a != 0. Вход заведомо соответствует этим условиям; корни вычисляются как вещественные числа.

Знак дискриминанта должен определяться точно для этих исходных целых. При отрицательном дискриминанте выведите сообщение Действительных корней нет.. При нулевом дискриминанте выведите только один корень, при положительном — только два корня в любом порядке, разделённые пробельными символами. Корни записывайте конечными числами в десятичной или экспоненциальной форме с точкой; количество знаков не фиксируется. Пробельные символы по краям вывода и завершающий перевод строки несущественны.

Разместите исходники в src/main/java. Класс запуска — Main без пакета; после компиляции запускайте его командой java -cp out Main с указанными аргументами. Допустима любая форма main, которую JDK 25 поддерживает при таком запуске. Вспомогательные классы и методы выбирайте самостоятельно.

Для каждого математического корня xx выведенное значение rr должно удовлетворять условию:

|r−x|≤10−8+10−12|x|. |r-x| \leq 10^{-8} + 10^{-12}|x|.

Например, коэффициенты 1 -3 2 дают корни 1 и 2, 1 -2 1 — один корень 1, а 1 0 1 — отсутствие действительных корней.

Покажите случаи положительного, нулевого и отрицательного дискриминанта. Объясните типы промежуточных вычислений и соблюдение допуска корней.

Консольная программа выводит результат без приглашений к вводу. Числа разделяются пробельными символами; десятичный разделитель — точка.

Единственный файл решения — Main.java из src/main/java, без объявления пакета. Вспомогательные классы и методы можно определить в нём.

Открытые примеры

Аргументы 1 -3 2 дают два корня 1 и 2 в любом порядке. Для каждого математического корня x допустимо отклонение 1e-8 + 1e-12*abs(x); оформление чисел остаётся свободным в пределах условия.

Для аргументов 1 -2 1 выводится один корень 1 с допуском 1e-8 + 1e-12. Два одинаковых числа или определённая фраза для этого случая не требуются.
