Сложность: Средний

Подсчитайте и выведите число локальных минимумов квадратной матрицы int[][]. Соседями элемента считаются существующие элементы с общей стороной или углом. Позиция является локальным минимумом, если её значение строго меньше значения каждого соседа. На краю учитываются только существующие соседи; равный сосед исключает строгий минимум.

Фиксированная исходная матрица имеет размер 3×3:

-3  0  3
 2 -1  0
 1  3 -2

Для проверки используйте матрицы размером не менее 2×2.

Имя класса, методы, форму main, способ задания данных и оформление результата выберите самостоятельно. Алгоритм не предписан.

Покажите исходники и результат. Объясните состав соседей для угловой и внутренней позиции, а также отличие строгого сравнения от нестрогого.

Сдайте файл Example.java из src/main/java стартового проекта без объявления пакета.
