Сложность: Средний

В каждом слове текста замените k-ю букву заданным символом. Буквы исходного слова нумеруются с единицы. Если k больше длины слова, слово не изменяйте. Границы слов определяются до замены; порядок слов и все исходные разделители сохраняются.

Допустимый текст состоит из латинских букв A–Z/a–z, русских букв А–Я/а–я с Ё/ё, цифр 0–9, знаков препинания ASCII, пробелов, табуляций и переводов строки. Составные сочетания Unicode не допускаются. Строка не равна null и может быть пустой; единица обработки — один char. Слово — максимальная непустая последовательность букв указанного алфавита. Цифры и все небуквенные символы разделяют слова. Если слов нет, текст остаётся прежним.

Используйте JDK 25 и отдельную программу, запускаемую командой java Main. Форму точки входа выберите самостоятельно. Программа получает ровно три корректных аргумента: исходный текст целиком, десятичное положительное k в диапазоне int и строку из одного заменяющего символа допустимого алфавита. Стандартный ввод не используется.

Выведите только преобразованный текст и завершающий перевод строки. Команда java Main "кот, я!" 2 "*" даёт к*т, я!; java Main "кот дом" 2 "*" — к*т д*м. Команда java Main "" 2 "*" передаёт пустой текст и выводит пустую строку. Алгоритм, вспомогательные методы и их имена выберите самостоятельно.

Представьте исходники и воспроизводимые примеры: короткое слово, слова рядом с цифрой и табуляцией, текст без слов и разные слова равной длины. Объясните границы слов в исходной строке и почему результат замены не меняет границы ещё не обработанных исходных слов.

Единственный файл решения — Main.java из src/main/java, без объявления пакета. Вспомогательные классы и методы можно определить в нём.

Открытые примеры

С аргументами "кот, я!", "2", "*" программа выводит точный текст к*т, я! и завершающий LF или CRLF. С аргументами "", "2", "*" выводится только один LF или CRLF. Стандартный ввод в обоих запусках не используется.
