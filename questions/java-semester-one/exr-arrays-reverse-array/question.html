Сложность: Начальный

Выведите элементы заданного int[] от последнего к первому, не изменяя сам массив.

Стандартный ввод содержит неотрицательную длину n, затем ровно n значений типа int, разделённых пробельными символами. Выведите только элементы в обратном порядке через пробельные символы. Для 4 7 -2 7 0 результат — 0 7 -2 7; для 0 вывод не содержит чисел. При пустом стандартном вводе используйте демонстрационный массив, который выберите в исходнике.

Точка входа — Main.main(String[] args). Алгоритм, вспомогательные методы и организацию программы выберите самостоятельно.

Автоматические 80% проверяют вывод на заданных входах. Использование массива, сохранность его компонентов в ходе вывода и ветвь выбранного демонстрационного массива оцениваются по сданному исходнику в ручных 20%. Не переставляйте компоненты даже с последующим восстановлением массива.

Сдайте файл Main.java из src/main/java стартового проекта без объявления пакета.

Открытые примеры

Запустите программу без аргументов. Ввод 4 7 -2 7 0 с последующим EOF даёт 0 7 -2 7. В отдельном запуске ввод 0 с последующим EOF не даёт чисел или другого текста; пробельное оформление допустимо.
