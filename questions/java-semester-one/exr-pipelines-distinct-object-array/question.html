Сложность: Средний

Разработайте метод, который через Stream API получает массив объектов и возвращает новый массив без дубликатов. Используйте лямбду или ссылку на конструктор массива при получении результата.

Выберите собственную модель с полями int id и ненулевым String name. Два объекта равны, когда совпадают оба поля; регистр имени значим. Обеспечьте согласованные equals и hashCode: можно реализовать их в обычном классе либо использовать подходящий record.

Массив и его элементы ненулевые. Сохраните порядок первого появления и ссылку на первый объект из каждой группы равных. Для отдельных объектов (1, "A"), (2, "B"), (1, "A") результат содержит первые два объекта. Исходный массив и объекты не меняются; пустой массив даёт новый пустой массив.

Предъявите модель и правило равенства. Покажите, какие именно ссылки из исходного массива остаются в новом результате, включая случай пустого входа.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Открытые примеры

Созданы отдельные объекты A = (1, "A"), B = (2, "B"), C = (1, "A"). Для массива [A, B, C] результат — новый массив [A, B] с исходными ссылками на первые вхождения. Исходный массив и данные всех трёх объектов сохраняются.

Для пустого массива той же модели результат — новый пустой массив.

Единственный файл решения — Study.java, без объявления пакета. Решение, вспомогательные классы и методы размещайте в нём.
