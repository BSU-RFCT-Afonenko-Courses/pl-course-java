Сложность: Средний

Это один из двух вариантов обязательного выбора: выполните эту задачу либо «Правильность расстановки скобок».

Сложите два многочлена, представленные HashMap<Integer, Double>. Ключ — неотрицательная целая степень, значение — конечный коэффициент. Карты, ключи и значения отличны от null. Отсутствующая степень имеет коэффициент ноль; пустая карта представляет нулевой многочлен. Гарантируется, что математическая сумма двух коэффициентов каждой степени по модулю не превосходит Double.MAX_VALUE.

Результат — самостоятельная HashMap с суммой коэффициентов для каждой степени; исходные карты сохраняются. Нулевые коэффициенты можно хранить явно или удалять. Пусть r — математическая сумма входных коэффициентов данной степени, a — полученный коэффициент. Допустима погрешность abs(a - r) <= 1e-9 + 1e-12 * abs(r). Отсутствующий коэффициент результата при сравнении считается нулём. Порядок обхода карты свободен.

Для {0: 1, 2: 3} и {1: 2, 2: -3} получается {0: 1, 1: 2}; пара 2: 0 также допустима. Используйте HashMap; допустимы merge или явный getOrDefault/put.

Предъявите исходники и консольную демонстрацию: общая степень, степени только одного входа, взаимное уничтожение коэффициентов и пустой вход. Покажите сохранность исходных карт и сравнение по допуску из условия. Имена вспомогательных методов и классов и формат показа результатов выбирайте самостоятельно в пределах файлов для сдачи.

Вход для проверки

Вход стартера возвращает самостоятельную HashMap суммы. Входы сохраняются, отсутствие степени означает ноль; явные нулевые коэффициенты разрешены. Для каждой степени применяется опубликованный смешанный допуск, в том числе при больших конечных коэффициентах. Сигнатуры входа из стартера обязательны.

Открытые примеры

Нулевая сумма общей степени. Сложите карты коэффициентов {0: 1, 2: 3} и {1: 2, 2: -3}. У результата коэффициенты степеней 0 и 1 равны 1 и 2; остальные равны нулю в допуске abs(a - r) <= 1e-9 + 1e-12 * abs(r). Нулевые записи можно оставить или удалить. Результат — самостоятельная HashMap, входы сохраняются.

Два нулевых многочлена. Две пустые HashMap дают самостоятельную нулевую HashMap. Явные нулевые записи допустимы; исходные карты сохраняются.

Сдайте Study.java без объявления пакета, сохранив объявления входа из стартера.
