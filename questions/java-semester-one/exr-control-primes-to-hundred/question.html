Сложность: Средний

Выведите по возрастанию все простые числа от 2 до 100 включительно. Простое число — целое больше единицы, имеющее только два положительных делителя: единицу и себя. Ввод не требуется; каждое найденное число выведите один раз.

Сохраните в стартовом проекте запускаемый класс Main без объявления пакета. После компиляции программа запускается командой java -cp out Main без аргументов. Можно использовать любую форму main, которую допускает такой запуск в JDK 25. Алгоритм, вспомогательные методы и остальные классы выбирайте самостоятельно.

Покажите полученную последовательность и объясните проверку простоты на выбранном простом и составном числе, а также границы диапазона.

Консольная программа выводит результат без приглашений к вводу. Числа разделяются пробельными символами; десятичный разделитель — точка.

Сдайте файл Main.java из src/main/java стартового проекта без объявления пакета.

Открытые примеры

При запуске без входных данных для диапазона от 2 до 100 числа идут по возрастанию с пробельными разделителями: первое — 2, последнее — 97. Число 7 встречается один раз, 9, 1 и 100 отсутствуют; каждое найденное простое выводится один раз.
