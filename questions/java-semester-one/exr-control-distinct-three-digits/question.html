Сложность: Средний

Сначала введите неотрицательное целое n, затем ровно n чисел типа int. Выведите в исходном порядке все числа с тремя различными цифрами в десятичной записи модуля: подходят и 123, и -123; знак не является цифрой. Сохраняйте знак и повторные вхождения. Если подходящих чисел нет, в том числе при n = 0, выведите «Подходящих чисел нет».

Сохраните в стартовом проекте запускаемый класс Main без объявления пакета. После компиляции программа запускается командой java -cp out Main без аргументов. Можно использовать любую форму main, которую допускает такой запуск в JDK 25. Алгоритм, вспомогательные методы и остальные классы выбирайте самостоятельно.

Покажите отрицательное число, повторное вхождение и пустой набор. Объясните проверку количества и различия цифр без учёта знака.

Консольная программа выводит результат без приглашений к вводу. Числа разделяются пробельными символами; десятичный разделитель — точка.

Сдайте файл Main.java из src/main/java стартового проекта без объявления пакета.

Открытые примеры

Передайте 6 123 -123 112 99 1000 123, затем EOF. Первое число задаёт количество элементов; вывод содержит 123 -123 123 в этом порядке. Знак и повтор сохраняются, а 112, 99 и 1000 не подходят. Числа можно разделять пробельными символами.

Ввод 0 с последующим EOF и без элементов даёт точное сообщение Подходящих чисел нет.
