Сложность: Высокий

Создайте класс для представления рациональной дроби парой чисел m и n. Реализуйте методы сложения, вычитания, умножения и деления объектов. Объявите и инициализируйте массив из k дробей, организуйте ввод и вывод его элементов. Передайте массив в метод, который прибавляет к каждому элементу с чётным индексом следующий за ним элемент.

Числитель и знаменатель — целые числа; знаменатели ненулевые, делитель не представляет ноль. Подберите данные, для которых промежуточные целочисленные результаты вашего способа вычисления помещаются в long. Значение результата должно совпадать с математической дробью; сокращение и расположение знака в этой карточке свободны.

Массив и его элементы не равны null, k может быть нулём. У чётного индекса 0, 2, 4, … новое значение равно сумме прежнего значения и следующей дроби. Нечётные элементы и последний чётный элемент без соседа сохраняют значения. Например, [1/2, 1/3, 2/5] превращается в [5/6, 1/3, 2/5]. Операции могут менять получателя либо возвращать новый объект: выберите один договор и явно укажите его в демонстрации. Преобразование массива должно выполнять описанное изменение значений и при повторяющихся ссылках на один объект. Сигнатуры и имена класса и методов выбирайте самостоятельно.

Предъявите четыре арифметические операции, ввод и вывод массива и его преобразование. На примере с повторными ссылками объясните выбранный договор операций и сохранение нечётных значений.

Вход для проверки

Создайте собственный класс дроби и его четыре операции. Входы стартера предоставляют проверке реальные дроби и массив, включая повторные ссылки. Арифметика может менять получателя или возвращать новый объект: назовите выбранный договор в демонстрации; вход возвращает полученный результат. Преобразование массива использует прежние значения позиций, изменяя только чётные позиции с правым соседом. Сохраните предусмотренные ввод и вывод элементов массива. Сохраните обязательные объявления входа из стартера; внутреннее устройство решения и формат демонстрации выбирайте самостоятельно в пределах условия.

Единственный файл решения — Study.java из src/main/java, без объявления пакета. Предметные и вспомогательные классы можно определить в нём как вложенные или неоткрытые классы верхнего уровня. Методы и реализацию выбирайте самостоятельно; демонстрацию также можно разместить в этом файле.

Открытые примеры

Четыре операции и последний элемент без пары. Для каждой операции отдельно возьмите исходные дроби 1/2 и 1/3. Сумма равна 5/6, разность — 1/6, произведение — 1/6, частное — 3/2. Массив разных объектов [1/2, 1/3, 2/5] после преобразования имеет значения [5/6, 1/3, 2/5]. Сравниваются рациональные значения дробей.

Один объект в четырёх позициях. Пусть x представляет 1/2, а массив содержит [x, x, x, x]. После преобразования значения позиций равны [1, 1/2, 1, 1/2]. Тождество результирующих ссылок свободно.
