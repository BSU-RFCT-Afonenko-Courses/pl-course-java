Сложность: Высокий

Выполните циклический сдвиг квадратной матрицы int[][] на k позиций в выбранном направлении: вправо, влево, вверх или вниз. При горизонтальном сдвиге сохраняется номер строки, при вертикальном — номер столбца. Элементы, вышедшие за край, возвращаются с противоположной стороны. Выведите полученную матрицу; число строк и столбцов сохраняется.

Фиксированная исходная матрица имеет размер 3×3:

-3  0  3
 2 -1  0
 1  3 -2

Для k = 1 покажите все четыре направления. Каждое преобразование применяется к исходному состоянию. Ожидаемые строки результатов:

  • вправо: (3, -3, 0), (0, 2, -1), (-2, 1, 3);
  • влево: (0, 3, -3), (-1, 0, 2), (3, -2, 1);
  • вверх: (2, -1, 0), (1, 3, -2), (-3, 0, 3);
  • вниз: (1, 3, -2), (-3, 0, 3), (2, -1, 0).

Сдвиг должен учитывать произвольное неотрицательное k, включая несколько полных оборотов. Для размера 3 сдвиг на 3 сохраняет расположение, а сдвиг на 4 даёт результат сдвига на 1 в выбранном направлении.

Обязательные базовые имена и сигнатуры приведены в каноническом стартере задания, доступном по ссылке ниже. Реализуйте его вычислительный метод: он получает матрицу, величину и направление сдвига и возвращает полученную матрицу. Обозначения направлений указаны рядом с методом. Разрешены изменение переданной матрицы и создание нового массива. Алгоритм, вспомогательные классы и методы, способ задания данных, форму main и оформление своей демонстрации выберите самостоятельно.

Представьте исходники и команду запуска. Объясните соответствие исходной и новой координаты; покажите обычный случай и допустимый сдвиг, на котором видно возвращение через край или учёт полных оборотов.

Сдайте файл Study.java из src/main/java стартового проекта без объявления пакета.

Открытые примеры

Для исходной матрицы [[-3,0,3],[2,-1,0],[1,3,-2]] каждый вызов Study.shift со сдвигом 1 применяется к исходному состоянию. Направления 0, 1, 2, 3 дают соответственно:

  • вправо: [[3,-3,0],[0,2,-1],[-2,1,3]];
  • влево: [[0,3,-3],[-1,0,2],[3,-2,1]];
  • вверх: [[2,-1,0],[1,3,-2],[-3,0,3]];
  • вниз: [[1,3,-2],[-3,0,3],[2,-1,0]].

Для той же исходной матрицы сдвиги вправо на 0 и 3 оставляют [[-3,0,3],[2,-1,0],[1,3,-2]]. Сдвиг вправо на 4 даёт [[3,-3,0],[0,2,-1],[-2,1,3]], как сдвиг на одну позицию.
