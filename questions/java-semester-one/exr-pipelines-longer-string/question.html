Сложность: Начальный

Определите собственный функциональный интерфейс с одним абстрактным методом из двух String в String. Реализуйте его лямбдой, выбирающей более длинную строку; длина измеряется кодовыми единицами char через String.length().

Оба аргумента ненулевые, пустые строки допустимы. При равной длине верните значение первой строки. Например, для "ab" и "XYZ" результат "XYZ", для "ab" и "cd" — "ab", для двух пустых строк — пустая строка. Имена интерфейса и метода свободны.

Предъявите собственный интерфейс и лямбду. Объясните выбор при равной длине и покажите работу с пустыми строками.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Открытые примеры

Для строк "ab" и "XYZ" результат — "XYZ".

Для строк одинаковой длины "ab" и "cd" результат — первая строка, "ab".

Единственный файл решения — Study.java, без объявления пакета. Решение, вспомогательные классы и методы размещайте в нём.
