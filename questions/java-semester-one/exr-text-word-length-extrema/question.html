Сложность: Средний

Найдите все слова максимальной и все слова минимальной длины в тексте. В каждом списке сохраните порядок появления и все повторные вхождения. Если все слова одной длины, оба списка совпадают.

Допустимый текст состоит из латинских букв A–Z/a–z, русских букв А–Я/а–я с Ё/ё, цифр 0–9, знаков препинания ASCII, пробелов, табуляций и переводов строки. Составные сочетания Unicode не допускаются. Строка не равна null и может быть пустой. Слово — максимальная непустая последовательность букв этого алфавита. Цифры и все небуквенные символы разделяют слова. Длина слова — число букв, каждая занимает один char.

Используйте JDK 25 и отдельную программу, запускаемую командой java Main. Форму точки входа выберите самостоятельно. Единственный аргумент — исходный текст целиком; он всегда передан, в том числе для пустого текста. Стандартный ввод не используется.

Если слова есть, выведите две строки: Максимумы: и список слов через один обычный пробел, затем Минимумы: и соответствующий список. После последнего слова пробела нет. Для java Main "кот, дом и кот!" вывод имеет вид:

Максимумы: кот дом кот
Минимумы: и

Если слов нет, выведите одну строку Слов нет. Команда java Main "" передаёт один пустой аргумент и выводит Слов нет. Алгоритм и вспомогательные методы выберите самостоятельно.

Представьте исходники и воспроизводимые примеры: короткое слово, слова рядом с цифрой и табуляцией, текст без слов и разные слова равной длины. Покажите сохранение повторов. Объясните, как границы слов в исходном тексте определяют состав списков и почему построение вывода не сдвигает эти границы.

Единственный файл решения — Main.java из src/main/java, без объявления пакета. Вспомогательные классы и методы можно определить в нём.

Открытые примеры

С единственным аргументом "кот, дом и кот!" программа выводит две строки:

Максимумы: кот дом кот
Минимумы: и

Стандартный ввод не используется; после последней строки LF или CRLF необязателен.

Для единственного аргумента "кот дом кот" оба списка совпадают:

Максимумы: кот дом кот
Минимумы: кот дом кот

Правило о необязательном завершающем переводе строки сохраняется.
