Сложность: Средний

В классе A объявлен метод void f() throws FileNotFoundException, а класс B extends A пока пуст. Переопределите f() в классе B тремя допустимыми способами, не вызывающими ошибку компиляции. Каждый вариант оформите как отдельную небольшую программу.

Сохраните заданное наследование и сигнатуру f(). Имена дополнительных классов выберите самостоятельно в пределах файлов для сдачи. Предъявите три версии и результаты их раздельной компиляции; объясните допустимость каждого объявления исключений. Определённый вывод программы не требуется.

Для сдачи подготовьте архив solution.zip с файлами cases/same/src/main/java/Version.java, cases/narrow/src/main/java/Version.java и cases/none/src/main/java/Version.java. Каждый вариант компилируется независимо; дополнительные классы размещайте в соответствующем файле без объявления пакета.
