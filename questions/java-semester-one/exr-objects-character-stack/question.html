Сложность: Средний

Создайте класс Stack с открытым конструктором Stack(int capacity) и методами public void push(char value), public char pop(). Закрытый массив хранит символы. Положительная ёмкость задаётся конструктором и остаётся постоянной; конструктору передают только положительную ёмкость.

push помещает символ на вершину. pop возвращает и удаляет последний помещённый символ. Допустим любой char, кроме нулевого символа: он зарезервирован для отказа.

  • Неудачный push печатает отдельную строку Стек переполнен.
  • Неудачный pop печатает отдельную строку Стек пуст и возвращает '\0'.
  • Успешные операции ничего не печатают.
  • Отказ сохраняет хранимые символы, их порядок и вершину.

Предъявите исходники и консольную демонстрацию заполнения, обоих отказов и порядка извлечения. Для ёмкости 2: после push('A'), push('B') и отказа push('C') вызовы pop() дают B, A; следующий отказ возвращает '\0'. Объясните, почему отказ третьего push не меняет вершину и последующие pop сохраняют этот порядок.

Внутренние индексы, вспомогательные методы и способ запуска демонстрации выбирайте самостоятельно. Различайте сообщения самих операций стека и вывод возвращённых значений демонстрационной программой.

Вход для проверки

Сохраняются заданные Stack(int), public push(char) и public pop(). Технический вход стартера вызывает именно их на вашем Stack; сообщения операций и возвращаемые символы наблюдаются раздельно от собственного вывода демонстрации. Сохраните обязательные объявления входа из стартера; внутреннее устройство решения и формат демонстрации выбирайте самостоятельно в пределах условия.

Для сдачи используйте файлы Stack.java и Study.java из src/main/java стартового проекта. Разместите их в двух редакторах без объявления пакета. Вспомогательные классы и методы можно определить в этих файлах; демонстрацию можно разместить в одном из них, без третьего исходника.

Открытые примеры

Порядок извлечения. В стек ёмкости 2 поместите A, затем B. Два вызова pop() возвращают B, затем A. Успешные операции ничего не печатают.

Отказы и продолжение работы. В стеке ёмкости 1 выполните pop(), push('X'), push('Y'), два pop(), push('Z'), pop(). Извлечения возвращают \0, X, \0, Z. За всю последовательность операции печатают ровно три отдельные строки: «Стек пуст», «Стек переполнен», «Стек пуст». Успешные действия молчат; отказ помещения Y сохраняет ранее помещённый X.
