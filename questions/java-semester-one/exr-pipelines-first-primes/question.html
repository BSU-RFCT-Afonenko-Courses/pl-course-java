Сложность: Высокий

Выведите первые N простых чисел в возрастающем порядке. Вход N — целое число от 0 до 10000 включительно. Простое число — целое больше единицы, имеющее ровно два положительных делителя: единицу и себя.

Используйте последовательный Stream API и генератор последовательности (iterate, generate или их варианты для примитивных потоков). Способ проверки простоты выберите самостоятельно. Для N = 5 результат 2 3 5 7 11, для N = 0 вывод пуст. Между числами допустимы пробелы или переводы строк.

Предъявите вывод для обычного N и для нуля. Объясните генератор, проверку простоты и ограничение числа результатов.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Открытые примеры

При N = 5 печатается последовательность 2, 3, 5, 7, 11. Числа разделяются пробелами или переводами строк.

При N = 0 вывод последовательности пуст.

Единственный файл решения — Study.java, без объявления пакета. Решение, вспомогательные классы и методы размещайте в нём.
