Сложность: Высокий

Создайте таблицу истинности для логических операций, представляя истину числом 1, ложь — числом 0. Печатайте заголовок и четыре строки значений. Таблица содержит колонки P, Q, AND, OR, XOR, NOT для всех сочетаний P и Q; NOT относится к P.

Входные данные не требуются. Первая непустая строка вывода — заголовок P Q AND OR XOR NOT, далее идут четыре строки по шесть значений 1 или 0. Имена колонок и значения разделяйте пробельными символами; табуляция необязательна. Порядок четырёх сочетаний выберите самостоятельно, каждое сочетание должно встретиться ровно один раз. Пустые строки, пробелы по краям строк и завершающий перевод строки несущественны.

Разместите исходники в src/main/java. Класс запуска — Main без пакета; после компиляции запускайте его командой java -cp out Main. Допустима любая форма main, которую JDK 25 поддерживает при таком запуске. Вспомогательные классы и методы выбирайте самостоятельно.

Покажите все четыре сочетания и объясните соответствие логических результатов значениям 1 и 0, включая отрицание P.

Консольная программа выводит результат без приглашений к вводу. Числа разделяются пробельными символами; десятичный разделитель — точка.

Единственный файл решения — Main.java из src/main/java, без объявления пакета. Вспомогательные классы и методы можно определить в нём.

Открытые примеры

Запустите программу без входных данных. Под заголовком P Q AND OR XOR NOT строка для P=1, Q=0 содержит 1 0 0 1 1 0, а для P=0, Q=0 — 0 0 0 0 0 1. Всего нужны четыре сочетания, каждое ровно один раз; порядок строк и пробельное оформление колонок свободны, табуляция необязательна.
