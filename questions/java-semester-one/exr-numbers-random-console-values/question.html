Сложность: Начальный

Получите десять псевдослучайных целых чисел от 0 до 99 включительно. Используйте java.util.Random с начальным значением 42 и значения nextInt(100). Дважды покажите одну и ту же последовательность: в строке и по одному числу в строке.

Входные данные не требуются. Выведите только две формы последовательности: одну строку из десяти чисел и десять строк по одному числу. Строка из десяти чисел может идти первой или последней. Внутри неё числа разделяются пробельными символами; пустые строки, пробелы по краям строк и завершающий перевод строки несущественны.

Разместите исходники в src/main/java. Класс запуска — Main без пакета; после компиляции запускайте его командой java -cp out Main. Допустима любая форма main, которую JDK 25 поддерживает при таком запуске. Вспомогательные классы и методы выбирайте самостоятельно.

Объясните по исходнику начальное значение генератора, границы nextInt(100) и сохранение одной последовательности при повторном выводе.

Консольная программа выводит результат без приглашений к вводу. Числа разделяются пробельными символами; десятичный разделитель — точка.

Единственный файл решения — Main.java из src/main/java, без объявления пакета. Вспомогательные классы и методы можно определить в нём.

Открытые примеры

В демонстрации Random с начальным значением 42 создаёт десять значений nextInt(100); отдельный протокол передачи начального значения не нужен. В одной строке должны находиться десять целых чисел от 0 до 99, а в десяти вертикальных строках — та же последовательность в том же порядке, по одному числу. Горизонтальная форма может идти первой или последней. Наличие 0 или 99 среди этих десяти не требуется, 100 вне диапазона; соответствие выбранному генератору сверяется также с исходником.
