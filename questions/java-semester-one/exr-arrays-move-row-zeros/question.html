Сложность: Средний

Преобразуйте каждую строку матрицы 3×3 так, чтобы нули располагались после всех ненулевых элементов. Взаимный порядок ненулевых элементов сохраняется. Разрешены преобразование на месте и создание нового массива.

Обязательный исходный пример — строки (-3, 0, 3), (2, -1, 0), (1, 3, -2). При пустом завершённом стандартном вводе используйте именно его. Для дополнительного входа допустимы матрицы 3×3 с целыми значениями от −3 до 3 включительно: передайте девять чисел через стандартный ввод построчно. Другие размеры, null, рваные матрицы и значения вне указанного диапазона не проверяются.

Выведите три строки по три числа, без подписей и приглашений к вводу. Внутри строки числа разделяются пробельными символами. Для обязательного примера строки результата — (-3, 3, 0), (2, -1, 0), (1, 3, -2). Проверьте также строку, начинающуюся с нулей, строку без нулей и полностью нулевую строку.

Точка входа — Main.main(String[] args). Алгоритм, вспомогательные методы и классы выберите самостоятельно. Покажите исходные данные и результат выбранных запусков; объясните, как сохраняется взаимный порядок ненулевых элементов.

Сдайте файл Main.java из src/main/java стартового проекта без объявления пакета.

Открытые примеры

Без аргументов, при пустом завершённом стандартном вводе, программа использует обязательную матрицу и выводит строки -3 3 0, 2 -1 0, 1 3 -2: по три числа с абсолютным допуском 1e-8.

Передайте строки 0 0 -3, 3 -1 2, 0 0 0 через стандартный ввод и завершите его. Получаются строки -3 0 0, 3 -1 2, 0 0 0: видны нули в начале исходной строки, строка без нулей и полностью нулевая строка.
