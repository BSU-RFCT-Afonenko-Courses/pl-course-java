Сложность: Средний

Напишите консольную программу, которая получает два аргумента — пути входного и выходного файлов — и копирует текст с заменой пробела U+0020 на дефис U+002D. Вход — конечный допустимый UTF-8-текст, включая пустой файл. Используйте Reader и Writer с явно выбранной кодировкой UTF-8 и try-with-resources. Остальные символы сохраняются, включая табуляции, переводы строк и отсутствие перевода после последней строки.

Относительные пути разрешаются от рабочего каталога процесса. Откройте вход прежде выхода. Отсутствующий выход создаётся, существующий перезаписывается. Если оба пути обозначают один существующий файл, отклоните операцию до открытия выхода и сохраните вход; учитывайте идентичность файла, включая разные записи пути к нему. Во время проверки файлы не меняются извне. Отсутствие входа сохраняет прежний выход и не создаёт новый. При отказе записи возможен частичный результат. Сообщите причину отказа; сообщение об успешном копировании допустимо только после успешного завершения.

Допустимо читать по одному символу или порциями в буфер. Имена классов и вспомогательных методов, текст и канал диагностики, а также коды завершения выберите самостоятельно.

Для входа Java text\nвторая строка результат — Java-text\nвторая-строка; здесь \n обозначает перевод строки, после последнего слова его нет. Покажите также пустой файл, табуляцию, разные разделители строк, отсутствующий вход при существующем выходе и отказ самокопирования. Предъявите исходник с try-with-resources и оба файла для сравнения. Подготовка: Чтение и запись, Интерфейс AutoCloseable.

Вход для воспроизводимой проверки

Сохраните обязательные сигнатуры входов из стартера. Они связывают проверку с вашим решением; наблюдаются его фактические действия и результаты. Формат отчёта и диагностики выбирайте в пределах условия.

Открытые примеры

Входной UTF-8-текст A B\tC\u00A0D\r\nE F копируется в ещё не существующий выходной файл как A-B\tC\u00A0D\r\nE-F. Здесь \t обозначает табуляцию, \u00A0 — неразрывный пробел, \r\n — CRLF; после F перевода строки нет. Вход сохраняется, меняются только обычные пробелы U+0020.

В рабочем каталоге файл text.txt содержит A B без конечного LF. Аргументы text.txt и ./text.txt обозначают один файл. Программа отклоняет такое копирование до усечения, объясняет отказ и сохраняет A B; сообщение об успехе не появляется.

Для сдачи используйте два редактора: Copy.java и Study.java, без объявления пакета. Сохраните объявления входа из стартера; вспомогательные классы и методы размещайте в этих файлах.
