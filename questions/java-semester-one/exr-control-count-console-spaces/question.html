Сложность: Средний

Читайте текст из стандартного ввода до первой точки или конца ввода и подсчитайте обычные пробелы U+0020. Точка завершает обработку и не учитывается; всё после неё игнорируется. Табуляция и переводы строки не считаются пробелами.

Входной текст имеет кодировку UTF-8. Выведите только целое количество пробелов. Например, a b c.after dot даёт 2, немедленная точка или пустой ввод — 0.

Точка входа — Main.main(String[] args); в ней допустимо объявить throws IOException. Способ чтения, форму цикла и вспомогательные методы выберите самостоятельно.

Представьте исходники и команды запуска. Покажите точку в начале, пробелы рядом с табуляцией, завершение по концу ввода и данные после точки. Объясните, что хранит счётчик после выбранного шага и к какой части входа относится его значение.

Сдайте файл Main.java из src/main/java стартового проекта без объявления пакета.

Открытые примеры

Для ввода a b c.after dot, завершённого EOF без перевода строки, результат равен 2: часть после точки не добавляет пробелов к счётчику. Пустой завершённый ввод даёт 0.
