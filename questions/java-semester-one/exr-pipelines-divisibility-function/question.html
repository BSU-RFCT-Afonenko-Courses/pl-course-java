Сложность: Начальный

Определите собственный функциональный интерфейс: его единственный абстрактный метод принимает int и возвращает boolean. Реализуйте интерфейс лямбда-выражением, которое проверяет делимость аргумента на 31 без остатка. Имена интерфейса и метода выберите самостоятельно.

Допустим весь диапазон int, включая отрицательные числа и ноль. Для 0, 31, -31 результат true, для 32 — false. Продемонстрируйте вызов метода через переменную вашего интерфейса.

Предъявите исходник интерфейса и лямбды, покажите результаты для положительного, отрицательного аргумента и нуля. Объясните, какой метод вызывается через переменную интерфейса.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Открытые примеры
