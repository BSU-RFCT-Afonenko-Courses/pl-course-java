Сложность: Средний

Напишите обобщённый метод, возвращающий максимальный элемент диапазона [begin, end) массива. Начальный индекс включается, конечный — нет. Сравнение выполняется через Comparable; результат сохраняет тип элемента.

Метод не изменяет массив и возвращает один из элементов выбранного диапазона. Если равных максимумов несколько, допустим любой из них. Массив и его элементы отличны от null; диапазон непуст и находится в границах массива: 0 <= begin < end <= array.length. Это предпосылки входных данных, проверять их программно не требуется. Допустимы границы Comparable<T> и Comparable<? super T>.

Примените один метод к массиву целых чисел и массиву строк. Покажите часть массива, не содержащую максимума всего массива, диапазон из одного элемента и несколько равных максимумов. Предъявите исходники и консольную демонстрацию; объясните, как граница параметра даёт операцию сравнения и сохраняется тип результата. Имя метода, содержащего класса и способ запуска выбирайте самостоятельно.

Сохраните обязательные сигнатуры открытого класса Study из канонического стартера, без объявления пакета. Решение можно разместить в нём или вызвать из него свои классы и методы. Дополнительный класс запуска и фиксированный формат демонстрации не требуются.

Используйте обобщённый вход maximum из стартера. Допустимы обе границы параметра — Comparable<T> и Comparable<? super T>. Внутренний метод может быть статическим или нестатическим, иметь другое имя и размещение.

Результат — та же ссылка на один из максимальных элементов диапазона [begin, end). Любой из равных максимумов допустим. Для сравнения важен знак compareTo, величина результата не обязана равняться 1 или −1. Массив сохраняет все элементы и их порядок. Область допустимых входов и демонстрация для целых чисел и строк остаются указанными в основном условии. Проверки не требуют null, пустого или неверного диапазона и не используют типы, доступные только границе с ? super T.
