Сложность: Высокий

Сначала введите неотрицательное целое n, затем ровно n чисел типа int. Найдите первое число, цифры в десятичной записи модуля которого идут слева направо в строго возрастающем порядке. Знак не учитывается: -128 подходит, 122 — нет. Одноцифровые числа, включая 0, также подходят. Выведите найденное число с исходным знаком; если его нет, в том числе при n = 0, выведите «Подходящих чисел нет».

Сохраните в стартовом проекте запускаемый класс Main без объявления пакета. После компиляции программа запускается командой java -cp out Main без аргументов. Можно использовать любую форму main, которую допускает такой запуск в JDK 25. Алгоритм, вспомогательные методы и остальные классы выбирайте самостоятельно.

Покажите отрицательное подходящее число, равные соседние цифры, одноцифровое число и пустой набор. Объясните, как выбирается первое подходящее значение и почему равные цифры не подходят.

Консольная программа выводит результат без приглашений к вводу. Числа разделяются пробельными символами; десятичный разделитель — точка.

Сдайте файл Main.java из src/main/java стартового проекта без объявления пакета.

Открытые примеры

Ввод 4 122 -128 137 0 с последующим EOF даёт только -128: 122 не подходит, знак найденного числа сохраняется, а последующие 137 и 0 не заменяют первое совпадение.

Для ввода 1 0, завершённого EOF, найденным числом является 0; сообщение об отсутствии подходящих значений не нужно.
