Сложность: Средний

Создайте класс для представления комплексного числа. Реализуйте методы сложения, вычитания, умножения и деления объектов. Создайте массив из n комплексных чисел и передайте его в метод для вычисления суммы и произведения элементов.

Действительная и мнимая части — double. Для демонстрации возьмите целые компоненты от −10 до 10; делитель не равен комплексному нулю. Массив ненулевой, содержит от 0 до 6 ненулевых объектов. Операции над массивом сохраняют его элементы: сумма пустого массива равна 0 + 0i, произведение — 1 + 0i. Для [1 + i, 1 - i] оба результата равны 2 + 0i.

Покажите каждую арифметическую операцию, сумму и произведение массива. Для каждой вычисленной компоненты абсолютная погрешность относительно математического результата не должна превышать 1e-8. Имена и сигнатуры, представление результата и оформление текста выбирайте самостоятельно; действительную и мнимую части должно быть возможно различить.

Предъявите исходник и объясните вычисление одной из операций, результаты пустого массива и сохранение его элементов.

Вход для проверки

Создайте собственный класс комплексного числа и предусмотренные операции. Через входы стартера наблюдаются реальные объекты, их компоненты и результаты четырёх операций, суммы и произведения массива. Операции над массивом сохраняют значения всех его элементов, в том числе при повторных ссылках; пустые сумма и произведение равны соответственно 0+0i и 1+0i. Сохраните обязательные объявления входа из стартера; внутреннее устройство решения и формат демонстрации выбирайте самостоятельно в пределах условия.

Единственный файл решения — Study.java из src/main/java, без объявления пакета. Предметные и вспомогательные классы можно определить в нём как вложенные или неоткрытые классы верхнего уровня. Методы и реализацию выбирайте самостоятельно; демонстрацию также можно разместить в этом файле.

Открытые примеры

Четыре операции и массив. Для каждой операции отдельно возьмите свежие значения a = 1 + 2i и b = 3 - 4i. Сложение даёт 4 - 2i, вычитание a - b — -2 + 6i, умножение — 11 + 2i, деление a / b — -0.2 + 0.4i. У массива [1 + i, 1 - i] сумма и произведение равны 2 + 0i. После каждого вызова компоненты элементов массива прежние. Абсолютная погрешность каждой вычисленной компоненты не превышает 1e-8.

Пустой массив. Для пустого ненулевого массива сумма равна 0 + 0i, произведение — 1 + 0i.
