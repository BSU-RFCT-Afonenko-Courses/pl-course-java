Сложность: Высокий

Перестройте матрицу 3×3, переставляя целые строки по неубыванию суммы их элементов. При одинаковых суммах сохраните исходный взаимный порядок строк. Порядок элементов внутри строки не меняется.

Можно написать собственную устойчивую сортировку строк или использовать устойчивую сортировку массива объектов. Конкретный алгоритм не предписан.

Обязательный исходный пример — строки (-3, 0, 3), (2, -1, 0), (1, 3, -2). При пустом стандартном вводе используйте именно его. Для дополнительного входа допустимы матрицы 3×3 с целыми значениями от −3 до 3 включительно: передайте девять чисел через стандартный ввод построчно. Другие размеры, null, рваные матрицы и значения вне диапазона не проверяются.

Выведите три строки по три числа, без подписей и приглашений к вводу. Внутри строки числа разделяются пробельными символами. Обязательный пример уже упорядочен. Строки (2, -1, 0), (0, 1, 0), (0, 0, 0) должны дать (0, 0, 0), (2, -1, 0), (0, 1, 0): разные строки с равными суммами сохранили порядок.

Точка входа — Main.main(String[] args). Вспомогательные методы и организацию программы выберите самостоятельно.

Представьте исходники, команды и выбранные входы. Покажите перестановку строк обязательного примера и разные строки с равной суммой. Объясните, как выбранное решение сохраняет их взаимный порядок.

Подготовка: Характеристика строки и Устойчивость сортировки строк массива.

Сдайте файл Main.java из src/main/java стартового проекта без объявления пакета.

Открытые примеры

Без аргументов передайте через стандартный ввод строки 1 3 -2, -3 0 3, 2 -1 0, затем EOF. Результат — строки -3 0 3, 2 -1 0, 1 3 -2.

Для входных строк 2 -1 0, 0 1 0, 0 0 0, завершённых EOF, результат — 0 0 0, 2 -1 0, 0 1 0: две разные строки с равной суммой сохраняют взаимный порядок.
