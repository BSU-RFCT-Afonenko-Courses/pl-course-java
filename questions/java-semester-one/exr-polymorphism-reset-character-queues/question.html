Сложность: Высокий

Это один из двух вариантов обязательного выбора: выполните эту задачу либо «Перенос между очередями разных типов».

Используйте полный Очереди символов. Каждая задача самостоятельна: создайте три реализации по этому договору либо используйте собственные ранее написанные реализации.

Добавьте в ICharQ метод void reset() и реализуйте его в FixedQueue, CircularQueue, DynQueue. После сброса очередь пуста, индексы вернулись в начальное состояние, текущая ёмкость сохранена, включая уже увеличенную ёмкость DynQueue. Сброс пустой очереди допустим, ничего не печатает и оставляет её пустой. После сброса старые символы больше не извлекаются.

Предъявите исходники и консольную демонстрацию общего клиента через ссылки ICharQ для всех трёх реализаций: заполнение, частичное извлечение, сброс, повторное помещение и сброс пустой очереди. Для DynQueue сначала добейтесь роста и объясните по исходнику, почему сброс сохраняет текущую ёмкость.

Объясните различия повторного использования места у трёх реализаций, почему клиент может принять новую реализацию без новой ветви instanceof и почему для DynQueue не требуется отказ переполнения. Вспомогательные поля, методы и способ запуска свободны в пределах общего договора. Требуются интерфейсный клиент и закрытое массивное FIFO-хранение.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Через файловый диалог сдайте файлы CircularQueue.java, DynQueue.java, FixedQueue.java и ICharQ.java из src/main/java стартового проекта. Во всех файлах пакет не объявляйте. Вспомогательные классы и методы можно определить в этих файлах; демонстрацию можно разместить в одном из них, без дополнительного исходника.

Открытые примеры

Сброс после частичного извлечения. Для каждой из FixedQueue(2), CircularQueue(2), DynQueue(2) поместите A, B, извлеките A, выполните reset(), затем поместите X, Y. Два извлечения дают X, Y; старый B удалён. Успешные операции молчат. Сохранение текущей ёмкости проверяется отдельно по исходнику.

Пустая и уже выросшая очередь. FixedQueue(1) и CircularQueue(1) изначально пусты, а DynQueue(1) содержит A, B, C. Выполните сброс каждой очереди и повторный пустой сброс динамической, затем поместите X и дважды извлеките. Каждая очередь возвращает X, затем \0 и печатает «Очередь пуста» при пустом извлечении. Пустые сбросы молчат. Сохранение выросшей ёмкости DynQueue, не меньшей 3, предъявляется отдельно по исходнику.
