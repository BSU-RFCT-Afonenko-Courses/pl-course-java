Сложность: Средний

Напишите обобщённый метод подсчёта элементов массива, удовлетворяющих переданному свойству. Свойство задайте обобщённым интерфейсом с методом boolean test(T value). Подсчёт получает массив и объект, реализующий этот интерфейс; конкретное свойство не встраивается в алгоритм подсчёта.

Реализуйте два разных свойства обычными классами и примените один метод подсчёта к двум типам элементов. Например, можно считать нечётные целые числа и строки длиннее трёх символов. Названия и устройство классов выбирайте самостоятельно. Лямбды и потоки Stream в этой задаче не используются.

Массив, его элементы и объект проверки отличны от null; проверка свойства не меняет элемент. Программно проверять эти предпосылки не требуется. Метод не изменяет массив; для пустого массива результат равен нулю.

Предъявите исходники и консольную демонстрацию для двух типов. Покажите случаи, когда подходят некоторые элементы, все элементы, ни один, а также пустой массив. Для выбранных свойств укажите входные данные и ожидаемое количество. Объясните связь типа элемента с параметром test и почему алгоритм подходит для разных свойств. Имена интерфейса и метода подсчёта и способ запуска свободны в пределах файлов для сдачи.

Сохраните обязательные сигнатуры открытого класса Study из канонического стартера, без объявления пакета. Решение можно разместить в нём или вызвать из него свои классы и методы. Дополнительный класс запуска и фиксированный формат демонстрации не требуются.

Используйте обобщённый интерфейс свойства и вход count из стартера. Внешнее количество представляется int, достаточным для числа элементов Java-массива. Внутренний алгоритм может возвращать long, использовать свой интерфейс, другое имя и нестатический вызов; оболочка сохраняет количество и переданное свойство. Дополнительный внутренний интерфейс создавать не требуется, если решение использует Study.Property непосредственно.

Подсчёт определяется переданным объектом свойства для каждого данного массива. Пустой массив даёт 0; исходные элементы и их порядок сохраняются. Проверки передают свои обычные классы свойств, в том числе разные свойства для одного массива. Вы самостоятельно выбираете и реализуете два разных свойства обычными классами для двух типов и демонстрируете их; нечётность и длина строки больше трёх остаются примерами. Лямбды и Stream не используются. Новых требований к порядку или точному количеству вызовов test нет; передаваемые при проверке свойства чистые и детерминированные.

Открытые примеры

Два свойства. В Integer[]{1, 2, 3} число нечётных элементов равно 2. В String[]{"one", "four", ""} число строк длиной строго больше 3 равно 1.

Пустые массивы. Для пустых Integer[] и String[] подсчёт с теми же свойствами возвращает 0 и 0.

Сдайте Study.java без объявления пакета, сохранив объявления входа из стартера.
