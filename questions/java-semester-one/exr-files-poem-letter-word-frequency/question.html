Выберите короткое стихотворение Адама Мицкевича из общественного достояния и создайте UTF-8-файл; укажите название, автора и источник текста. До подсчёта зафиксируйте, какие символы считаются буквами, как выделяются слова и учитывается регистр.

Подсчёт охватывает весь файл. Выведите отдельно каждую различную букву с числом появлений и каждое различное слово с его частотой. Выберите воспроизводимый порядок вывода и зафиксируйте его вместе с правилами нормализации. Пустой файл даёт пустые наборы частот; покажите повтор слова в разных строках.

Открытые примеры

В этом примере UTF-8-файл содержит две строки с LF после каждой:

Polały się łzy me czyste, rzęsiste,

Для заранее выбранных правил «Unicode-буквы, нижний регистр, порядок первого появления» получаются 60 букв и 11 вхождений слов. Набор букв в этом порядке: p: 1, o: 2, l: 3, a: 3, ł: 2, y: 3, s: 8, i: 8, ę: 2, z: 4, m: 2, e: 9, c: 2, t: 3, r: 1, n: 2, d: 1, ń: 1, w: 1, k: 2. Набор слов: polały: 1, się: 1, łzy: 1, me: 2, czyste: 1, rzęsiste: 1, na: 1, dzieciństwo: 1, sielskie: 1, anielskie: 1. Повтор me учитывается в обеих строках. Другие допустимые заранее объявленные правила букв, слов, регистра, нормализации и порядка сохраняют силу; ожидания для них определяются выбранными правилами.

Пустой UTF-8-файл при тех же объявленных правилах даёт два пустых набора частот. Оформление отчёта свободно.
