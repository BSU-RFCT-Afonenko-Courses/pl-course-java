Модель точки и способ её создания выберите самостоятельно.

Обе координаты — целые числа от `-10000` до `10000` включительно. Список и его элементы ненулевые; число точек может быть нулевым. Расстояния сравниваются по их геометрическому значению. Допустим любой способ сравнения, сохраняющий этот порядок и равенство расстояний.

Сортировка устойчивая: точки с равными геометрическими расстояниями сохраняют исходный взаимный порядок, включая повторяющиеся точки. Исходный список и точки не меняются. Для `(1:10)` и `(2:0)` первой должна быть `(2:0)`; точки `(3:4)` и `(0:5)` остаются в исходном порядке. Пустой список даёт пустой вывод.

Покажите обычный порядок, равные расстояния, повторяющуюся точку и пустой список. Объясните лямбда-компаратор, устойчивость и сохранность исходных данных.
