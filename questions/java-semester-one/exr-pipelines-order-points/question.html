Сложность: Средний

Отсортируйте упорядоченный список точек плоскости по возрастанию расстояния от начала координат. Примените Stream API и лямбда-компаратор; отсортированный результат выведите, обозначая каждую точку как (X:Y). Между точками допустимы пробелы или переводы строк. Модель точки и способ её создания выберите самостоятельно.

Обе координаты — целые числа от -10000 до 10000 включительно. Список и его элементы ненулевые; число точек может быть нулевым. Расстояния сравниваются по их геометрическому значению. Для этого диапазона квадрат расстояния x * x + y * y целый, не превышает 200000000 и точно представим в int: его порядок совпадает с порядком расстояний. Допустим любой способ сравнения, сохраняющий этот порядок и равенство расстояний.

Сортировка устойчивая: точки с равными геометрическими расстояниями сохраняют исходный взаимный порядок, включая повторяющиеся точки. Исходный список и точки не меняются. Для (1:10) и (2:0) первой должна быть (2:0); точки (3:4) и (0:5) остаются в исходном порядке. Пустой список даёт пустой вывод.

Покажите обычный порядок, равные расстояния, повторяющуюся точку и пустой список. Объясните лямбда-компаратор, устойчивость и сохранность исходных данных.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Открытые примеры

Для упорядоченного списка (1:10), (2:0) обработка печатает (2:0) (1:10). Исходный список и сами точки сохраняются. Между точками допустимы пробелы или переводы строк.

Для списка (3:4), (0:5), (3:4) с равными расстояниями результат печатается в том же порядке: (3:4) (0:5) (3:4). Повтор сохраняется; список и точки остаются прежними. Разделители допустимы те же.
