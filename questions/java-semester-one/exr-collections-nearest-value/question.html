Сложность: Высокий

На базе коллекций реализуйте хранение чисел с добавлением, удалением и поиском ближайшего к запросу. В этой задаче хранимые значения и запросы — конечные double с модулем не больше 1e150. Расстоянием считается результат Java-выражения Math.abs(value - query); указанная граница исключает переполнение разности. Выберите хранимое значение с наименьшим таким расстоянием; при равенстве вычисленных расстояний — меньшее по Double.compare. Правило применяется ко всем хранимым значениям, включая случаи, когда округление даёт одинаковое расстояние для разных чисел.

Дубликат определяется результатом Double.compare(a, b) == 0: повторное добавление сохраняет состав, удаление отсутствующего числа также сохраняет его. -0.0 и +0.0 различаются; при равном расстоянии выбирается -0.0. Для пустого хранилища верните OptionalDouble.empty(), для непустого — выбранное число в OptionalDouble. Покажите поиск по обе стороны от запроса, равные расстояния и отсутствие элементов. Имена методов и устройство хранилища свободны; ограничение стоимости поиска не задаётся.

Предъявите исходник и наблюдения поиска. Объясните сравнение вычисленных расстояний, правило ничьей через Double.compare и результат для пустого хранилища.

Вход для проверки

Входы стартера создают ваше хранилище и вызывают добавление, удаление и поиск. Ближайшее определяется среди всех значений по вычисленному в Java Math.abs(value-query); равные вычисленные расстояния разрешаются через меньшее значение по Double.compare. Сравнение выполняется без нового допуска. Сигнатуры входа из стартера обязательны.

Открытые примеры

По обе стороны и на равном расстоянии. Добавьте 2, 8 и выполните запросы для 3, 7, 5. Результаты OptionalDouble содержат соответственно 2, 8, 2.

Равенство вычисленных расстояний. Добавьте -100, 0, 100 и выполните запрос для 1e150. Результат OptionalDouble содержит -100: выбирается минимальное значение среди всех значений с равными вычисленными расстояниями.

Сдайте Study.java без объявления пакета, сохранив объявления входа из стартера.
