Сложность: Начальный

Алфавит и единица счёта: Данные и границы текста.

Вставьте заданную подстроку после k-го символа текста. Вход — исходный текст, подстрока и целое k от 0 до длины текста включительно. Нумерация символов начинается с единицы: k = 0 означает вставку перед первым символом, а k, равное длине, — после последнего. Все символы исходного текста сохраняются. Для пустого текста допустимо только k = 0.

Выделите вставку в метод, принимающий исходный текст, фрагмент и позицию и возвращающий строку результата. Исходная строка сохраняется. Допустимые входы удовлетворяют указанным границам; отдельная обработка иных позиций не требуется. Пустой вставляемый фрагмент сохраняет текст.

Покажите примеры: "Java" и "!" при k = 0 дают "!Java", при k = 4 — "Java!"; пустой текст и "код" при k = 0 дают "код". Можно использовать substring и конкатенацию или StringBuilder; способ выберите самостоятельно.

Покажите метод и результаты его вызовов. Объясните, где проходит граница между частями исходной строки при вставке, включая пустую часть.

Сохраните обязательные имя класса и сигнатуру операции из канонического стартера и реализуйте её для переданных данных. Алгоритм, вспомогательные методы и классы, форму main, способ задания данных и оформление демонстрации выберите самостоятельно.

Если карточка не задаёт более узкий алфавит, входные строки состоят из латинских букв A–Z/a–z, русских букв А–Я/а–я с Ё/ё, цифр 0–9, знаков препинания ASCII, пробелов, табуляций и переводов строки. Составные сочетания Unicode не допускаются. Строки не равны null; пустая строка допустима. Символ и единица длины здесь — один char.

Единственный файл решения — Study.java из src/main/java, без объявления пакета. Вспомогательные классы, методы и демонстрацию можно разместить в нём.

Открытые примеры

Вызов Study.insert("Java", "!", 2) возвращает "Ja!va": граница вставки проходит после двух исходных символов.

Для текста "Java" и фрагмента "!" позиция 0 даёт "!Java", а позиция 4 — "Java!". Пустой текст с фрагментом "код" и позицией 0 даёт "код".
