Сложность: Средний

Отобразите таблицу истинности для логических операций Java. Колонки: P, Q, AND, OR, XOR, NOT; NOT означает отрицание P. Используйте табуляцию между колонками и включите все четыре сочетания P и Q.

Вход и результат: первая строка — P Q AND OR XOR NOT (между именами настоящая табуляция). Далее четыре строки по шесть значений true или false, также разделённых табуляцией. Порядок строк выберите самостоятельно. Например, для P = true, Q = false строка содержит true false false true true false. Ввод не требуется.

Точка входа — Main.main(String[] args).

Покажите таблицу целиком и объясните результаты операций для выбранной строки, включая отличие XOR от OR.

Единственный файл решения — Main.java из src/main/java, без объявления пакета. Вспомогательные классы и методы можно определить в нём.

Открытые примеры

В запуске без аргументов и входных данных заголовок имеет вид P\tQ\tAND\tOR\tXOR\tNOT, строка для true, false — true\tfalse\tfalse\ttrue\ttrue\tfalse, а для false, false — false\tfalse\tfalse\tfalse\tfalse\ttrue. Здесь \t обозначает настоящую табуляцию между колонками. Все четыре пары встречаются по одному разу в любом порядке; указанные строки не обязаны быть первой или последней.
