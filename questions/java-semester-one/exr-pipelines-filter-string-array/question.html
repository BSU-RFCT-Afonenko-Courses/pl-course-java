Сложность: Начальный

Получите через Stream API новый массив строк, длина которых строго больше переданного порога. Вход — ненулевой String[] без элементов null и неотрицательный порог int. Длина измеряется кодовыми единицами UTF-16 (char, результат String.length()). Пустые строки и пустой массив допустимы.

Сохраните порядок и все повторы подходящих строк; исходный массив не меняйте. Для {"a", "bb", "bb", "ccc"} при пороге 2 результат {"ccc"}, при пороге 1 — {"bb", "bb", "ccc"}. При пороге 0 из {"", "x"} остаётся {"x"}. Пустой вход и отсутствие совпадений дают новый пустой String[].

Покажите строгую границу длины, пустой отбор и сохранение повторов и исходного массива. По исходнику объясните, где создаётся поток и где получается новый массив.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Открытые примеры

Для массива {"a", "bb", "bb", "ccc"} и порога 1 фильтрация возвращает новый String[] с последовательностью {"bb", "bb", "ccc"}. Исходный массив сохраняется, порядок и повтор "bb" остаются.

Для пустого String[] и порога 0 результат — пустой String[], отличный от входного объекта. Вход остаётся пустым.

Единственный файл решения — Study.java, без объявления пакета. Решение, вспомогательные классы и методы размещайте в нём.
