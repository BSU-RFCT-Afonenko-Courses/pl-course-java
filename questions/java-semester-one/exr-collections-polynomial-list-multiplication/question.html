Сложность: Высокий

Умножьте многочлены, заданные двумя списками Double: элемент с индексом i является коэффициентом степени i. Списки и элементы отличны от null, длина каждого списка от 0 до 64, коэффициенты конечны и по модулю не больше 1000. Пустой список представляет нулевой многочлен.

Для непустых входов длиной m и n получите самостоятельный список длиной m + n - 1, включая нулевые старшие коэффициенты. Если хотя бы один вход пуст, результат — пустой список. Исходные списки сохраняются. Коэффициент результата степени k равен сумме произведений a[i] * b[j] по всем допустимым парам с i + j = k. При сравнении с этой математической суммой r допустима погрешность abs(result - r) <= 1e-6 + 1e-12 * abs(r).

Например, [1, 2] и [3, 4] дают [3, 10, 8]. Покажите также пустой вход, нулевые коэффициенты и взаимное уничтожение слагаемых.

Предъявите исходники, входные списки и результат. Сопоставьте степени с индексами; объясните длину результата и суммирование произведений для одного коэффициента.

Вход для проверки

Вход стартера возвращает самостоятельный список коэффициентов произведения. Сохраняются оба входа, длина m+n−1 для непустых входов и старшие нули; если хотя бы один вход пуст, результат пуст. Сравнение каждого коэффициента использует опубликованный смешанный допуск. Сигнатуры входа из стартера обязательны.

Открытые примеры

Совпадающие суммы степеней. Для списков коэффициентов [1, 2] и [3, 4] получается самостоятельный список [3, 10, 8] длиной 3. Оба входа сохраняются. При сравнении каждого коэффициента с математическим значением r действует допуск abs(result - r) <= 1e-6 + 1e-12 * abs(r).

Пустой множитель. Произведение [1, 0] и [] даёт пустой результат; оба исходных списка сохраняются.

Сдайте Study.java без объявления пакета, сохранив объявления входа из стартера.
