Сложность: Высокий

Сначала введите неотрицательное целое n, затем ровно n чисел типа int. Выведите в исходном порядке числа, десятичная запись модуля которых одинакова при чтении слева направо и справа налево. Знак не учитывается; -121, 121, 7 и 0 подходят, 10 — нет. Сохраняйте знак и все повторные вхождения. Если подходящих чисел нет, в том числе при n = 0, выведите «Подходящих чисел нет».

Сохраните в стартовом проекте запускаемый класс Main без объявления пакета. После компиляции программа запускается командой java -cp out Main без аргументов. Можно использовать любую форму main, которую допускает такой запуск в JDK 25. Алгоритм, вспомогательные методы и остальные классы выбирайте самостоятельно.

Покажите отрицательное число, повторные вхождения, нуль и пустой набор. Объясните сравнение цифр модуля и сохранение исходного порядка.

Консольная программа выводит результат без приглашений к вводу. Числа разделяются пробельными символами; десятичный разделитель — точка.

Сдайте файл Main.java из src/main/java стартового проекта без объявления пакета.

Открытые примеры

Ввод 6 -121 121 7 0 10 -121, завершённый EOF, даёт -121 121 7 0 -121 в исходном порядке. Число 10 отсутствует; знак, нуль и повтор -121 сохраняются. Пробельные разделители свободны.

Для ввода 0 с последующим EOF выводится точный текст Подходящих чисел нет.
