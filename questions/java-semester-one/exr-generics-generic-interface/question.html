Сложность: Начальный

Дан интерфейс IGenIF<T, V extends T> без методов. Его исходный файл входит в комплект. Объявите обобщённый класс MyClass, реализующий этот интерфейс и сохраняющий указанное отношение между параметрами типов.

Покажите компиляцию допустимого применения с Number, Integer. Отдельно скомпилируйте пример с Integer, Number и объясните отказ компилятора. Сохраните корректный вариант решения отдельно от примера, который должен вызвать ошибку компиляции.

Имена параметров типов, дополнительные параметры, конструкторы, модификаторы доступа выбирайте самостоятельно в пределах файлов для сдачи. Реализация интерфейса может быть унаследована, если требуемая связь типов сохраняется. Предъявите исходники обоих примеров и объясните различие между допустимой параметризацией и нарушением границы типа. [1]

Для сдачи подготовьте архив solution.zip с файлами src/main/java/IGenIF.java, src/main/java/MyClass.java, positive/src/main/java/Good.java и negative/src/main/java/Bad.java, без объявления пакета. Допустимый и ошибочный примеры компилируйте отдельно; вспомогательные классы размещайте в указанных файлах.

[1]
Г. Шилдт, Java: руководство для начинающих, 9-я изд. Науковий Світ, 2023, с. 522.
