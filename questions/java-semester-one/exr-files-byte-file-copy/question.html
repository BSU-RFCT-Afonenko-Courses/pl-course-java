Сложность: Высокий

Напишите консольную программу, которая получает два аргумента — пути входного и выходного файлов — и копирует текст с заменой пробела U+0020 на дефис U+002D. Вход — конечный допустимый UTF-8-текст, включая пустой файл. Используйте файловые потоки байтовых данных: заменяйте байт 0x20 на 0x2D, сохраняйте остальные байты. Табуляции, переводы строк и отсутствие перевода после последней строки должны сохраниться.

Относительные пути разрешаются от рабочего каталога процесса. Откройте вход прежде выхода. Отсутствующий выход создаётся, существующий перезаписывается. Если оба пути обозначают один существующий файл, отклоните операцию до открытия выхода и сохраните вход; учитывайте идентичность файла, включая разные записи пути к нему. Во время проверки файлы не меняются извне. Отсутствие входа сохраняет прежний выход и не создаёт новый. При отказе записи возможен частичный результат. Сообщите причину отказа; сообщение об успешном копировании допустимо только после успешного завершения.

Закрывайте каждый успешно открытый ресурс явным вызовом close(), включая выход по исключению и случай отказа при закрытии другого ресурса. Допустимо читать по одному байту или порциями в буфер. Имена классов и вспомогательных методов, текст и канал диагностики, а также коды завершения выберите самостоятельно.

Для входа Java text\nвторая строка результат — Java-text\nвторая-строка; здесь \n обозначает перевод строки, после последнего слова его нет. Покажите также пустой файл, табуляцию, разные разделители строк, отсутствующий вход при существующем выходе и отказ самокопирования. Предъявите исходник с явным закрытием и оба файла для сравнения. Подготовка: Чтение и запись, Ручное закрытие при исключении.

Вход для воспроизводимой проверки

Сохраните обязательные сигнатуры входов из стартера. Они связывают проверку с вашим решением; наблюдаются его фактические действия и результаты. Формат отчёта и диагностики выбирайте в пределах условия.

Открытые примеры

Входной UTF-8-файл содержит Java text\nвторая строка: между строками стоит LF, после последнего слова перевода строки нет. Выходного файла ещё нет. После запуска с двумя путями выход содержит Java-text\nвторая-строка, а вход остаётся прежним. Сообщение об успехе допустимо после завершения копирования. Здесь \n обозначает LF.

Если вход отсутствует, а выход уже содержит UTF-8-текст Сохранить без конечного LF, запуск с этими двумя путями сообщает причину отказа. Прежние байты выхода сохраняются, вход не создаётся, успех не заявляется.

Для сдачи используйте два редактора: Copy.java и Study.java, без объявления пакета. Сохраните объявления входа из стартера; вспомогательные классы и методы размещайте в этих файлах.
