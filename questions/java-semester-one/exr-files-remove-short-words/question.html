Для вывода результатов создайте новый каталог и файл средствами класса File. Из каждой строки файла удалите максимальное чётное количество слов длиной от трёх до пяти символов.

Вход: строки «one two elephant four», «a cat dog bee house». Разделитель — пробел. Если подходящих слов нечётное количество, оставьте последнее подходящее слово, чтобы число удалённых было максимальным чётным; порядок остальных слов сохраняйте.

Вход — UTF-8-текст; длину слова считайте в кодовых точках Unicode. Слово — непустая последовательность между ASCII-пробелами; несколько пробелов дают одну границу. Пунктуация внутри такой последовательности участвует в длине. Выводите сохранившиеся слова каждой строки через один пробел; полностью очищенная строка остаётся пустой. Для примера получатся elephant four и a. Добавьте строку без подходящих слов и пустой файл.

Предъявите исходник и оба файла. Покажите создание каталога и файла средствами File; объясните подсчёт кодовых точек и выбор последнего сохраняемого слова.

Вход для воспроизводимой проверки

Сохраните обязательные сигнатуры входов из стартера. Они связывают проверку с вашим решением; наблюдаются его фактические действия и результаты. Формат отчёта и диагностики выбирайте в пределах условия.

Открытые примеры

Входной UTF-8-файл содержит строки one two elephant four и a cat dog bee house, с LF после каждой. После обработки новый выход в новом каталоге содержит две строки: elephant four и a.

Если единственная строка входа — 😀😀😀 cat с конечным LF, результат содержит одну пустую физическую строку. Три символа 😀 считаются тремя кодовыми точками.
