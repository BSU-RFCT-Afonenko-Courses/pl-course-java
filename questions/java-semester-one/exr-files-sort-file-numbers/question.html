Для вывода результатов создайте новый каталог и файл средствами класса File. В текстовом файле содержатся целые числа. Прочитайте их и запишите содержимое в новый файл, отсортировав по возрастанию.

Входной UTF-8-файл содержит строку «7 −2 7 0 3 −5»; в фактическом файле используйте обычный ASCII-минус. Разделитель — пробельные символы, результат содержит те же числа и повторы.

Допустимы целые значения диапазона int, разделённые одним или несколькими ASCII-пробелами, табуляциями либо переводами строк. Пустой вход допустим. Выведите числа через один пробел в возрастающем порядке, сохранив повторы; последний перевод строки необязателен. Пример даёт -5 -2 0 3 7 7. Пути входа и нового результата задайте явно в демонстрации. Открывайте результат после чтения входа; при ошибке чтения новый файл не создаётся.

Предъявите входной и выходной файлы и исходник. Покажите создание каталога и файла средствами File и объясните, почему результат открывается после чтения входа.

Вход для воспроизводимой проверки

Сохраните обязательные сигнатуры входов из стартера. Они связывают проверку с вашим решением; наблюдаются его фактические действия и результаты. Формат отчёта и диагностики выбирайте в пределах условия.

Открытые примеры

Входной файл содержит 7 -2 7 0 3 -5 без конечного перевода строки. Каталога результата и самого результата ещё нет. После сортировки выход содержит -5 -2 0 3 7 7: между соседними числами ровно один пробел, конечный перевод строки допустим, но не обязателен.

Для входа 2147483647\t-2147483648\n2147483647, где \t — табуляция, а \n — LF, новый выход содержит -2147483648 2147483647 2147483647. Конечный перевод строки также необязателен.

Сдайте Study.java без объявления пакета, сохранив объявления входа из стартера.
