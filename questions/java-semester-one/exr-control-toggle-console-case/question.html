Сложность: Средний

Читайте текст из стандартного ввода до первой точки или конца ввода. Замените ASCII A–Z на a–z, а a–z на A–Z, используя разницу кодов 32. Остальные символы сохраните без изменения: цифры, знаки, пробелы, переводы строк, кириллицу и эмодзи. Точка не входит в результат; всё после неё игнорируется. Подсчитайте каждую изменённую ASCII-букву. Допустимо объявить throws IOException в main.

Вход и результат: ввод и вывод — UTF-8. Сначала выведите преобразованный текст, затем один дополнительный перевод строки, затем целое количество изменений и перевод строки. Ввод AБяz 👋🙂. даёт текст aБяZ 👋🙂 и счётчик 2. Немедленная точка или пустой ввод дают пустую строку и затем 0. Не применяйте преобразование ко всем символам без проверки ASCII-диапазона.

Точка входа — Main.main(String[] args).

Покажите ASCII-буквы рядом с кириллицей и эмодзи, точку в начале, завершение по EOF и данные после точки. Объясните изменение счётчика и применение разницы кодов только внутри указанных ASCII-диапазонов.

Сдайте файл Main.java из src/main/java стартового проекта без объявления пакета.

Открытые примеры

Передайте UTF-8 текст AБяz 👋🙂., затем EOF. Вывод сначала содержит точно aБяZ 👋🙂, затем один дополнительный перевод строки, число 2 и перевод строки. При LF полная запись — aБяZ 👋🙂\n2\n, где \n обозначает перевод строки.

Для UTF-8 ввода .Az, завершённого EOF, вывод состоит из пустой строки, затем 0 и перевода строки: при LF это \n0\n. Буквы после точки не выводятся и не увеличивают счётчик.
