Сложность: Средний

Создайте программу пузырьковой сортировки массива целых чисел. Используйте многократное сравнение и при необходимости обмен соседними элементами массива. Отобразите исходный массив и результат сортировки по возрастанию.

Исходные данные: 7, -2, 7, 0, 3, -5. На пустом и одноэлементном массивах преобразование не меняет содержимое; покажите также эти случаи.

Обязательные базовые имена и сигнатуры приведены в каноническом стартере задания, доступном по ссылке ниже. Реализуйте его вычислительный метод пузырьковой сортировки, возвращающий отсортированный массив. Разрешены сортировка переданного массива и сортировка его копии. Вспомогательные классы и методы, форму main, способ задания данных и оформление своей демонстрации выберите самостоятельно.

Покажите исходники и запуск. Объясните сравнение соседних элементов, условие обмена и завершение проходов на обычном и коротких массивах.

Сдайте файл Study.java из src/main/java стартового проекта без объявления пакета.

Открытые примеры

Вызов Study.sort для [7,-2,7,0,3,-5] возвращает [-5,-2,0,3,7,7]. Показ исходного массива и результата, а также пузырьковый способ проверяются отдельно в ручных 20% оценки; дополнительного обязательного API Main этот пример не задаёт.

Сортировка пустого массива возвращает [], а сортировка [7] — [7].
