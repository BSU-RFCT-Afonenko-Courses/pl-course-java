Сложность: Средний

Это один из двух вариантов обязательного выбора: выполните эту задачу либо «Сложение многочленов в хеш-карте».

Получите строку, отличную от null и состоящую только из (, ), [, ], {, }. Определите, можно ли сопоставить каждой открывающей скобке закрывающую того же вида с правильной вложенностью. Закрывающая скобка завершает последнюю ещё не закрытую пару. Результат — boolean; вход сохраняется.

Используйте стек: допустимы Deque/ArrayDeque или собственная реализация. Пустая строка и ([]{}) корректны; ([)], ) и (( некорректны.

Предъявите исходники и консольную демонстрацию этих границ и строки с несколькими соседними парами. Проследите состояние стека до первой ошибки вложенности и при завершении корректной строки. Имена вспомогательных методов и классов и способ запуска свободны в пределах файлов для сдачи. Справка: Очереди.

Вход для проверки

Вход стартера возвращает признак правильной расстановки для строки из шести скобочных символов. Пустая строка правильна; несовпадение типа, лишнее закрытие и незакрытое открытие дают false. Требуемый стек реализуйте самостоятельно или используйте Deque/ArrayDeque. Сигнатуры входа из стартера обязательны.

Открытые примеры

Вложенные пары. Проверка строки ([]{}) возвращает true.

Пустая строка и лишняя закрывающая скобка. Пустая строка даёт true, строка ) — false. Оба вызова относятся к одному опубликованному граничному примеру.

Сдайте Study.java без объявления пакета, сохранив объявления входа из стартера.
