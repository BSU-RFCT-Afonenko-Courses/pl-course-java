Сложность: Средний

Для готовой строки, отличной от null, подсчитайте частоту каждого английского слова с помощью HashMap. Слово — максимальная непустая последовательность букв A–Z и a–z; любой другой символ разделяет слова. Регистр значим. Исходная строка сохраняется; результат содержит все встреченные слова с положительным числом их вхождений. Порядок перечисления пар свободен.

Для Java java, code! Code code частоты равны Java → 1, java → 1, code → 2, Code → 1. Пустая строка и строка без английских букв дают пустую карту. Способ выделения слов и формат предъявления пар выберите самостоятельно.

Предъявите исходник и карту частот. Объясните границы слова, сохранение регистра и обновление счётчика в HashMap; покажите строку без английских букв.
