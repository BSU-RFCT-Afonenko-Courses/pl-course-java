Сложность: Средний

Программа получает произвольный массив строк-кодов, в том числе пустой. Массив и его элементы отличны от null. Каждый элемент — одно обращение; повторный код означает новое обращение к той же записи. Коды сравниваются с учётом регистра, без обрезки пробелов и иной нормализации.

Создайте собственный обычный класс ключа с неизменяемым строковым кодом, согласованными equals и hashCode. Используйте его экземпляры в HashSet для посещённых записей и в HashMap для числа обращений к каждой записи. Состав множества и частоты соответствуют всему массиву; вход сохраняется. Для пустого массива оба результата пусты. Готовые строки и record не заменяют собственный обычный класс ключа.

Покажите s17, s18, s17: различных записей 2, частоты s17 → 2, s18 → 1. Для повторных вхождений создавайте отдельные объекты ключей. Поиск новым равным ключом находит прежнюю частоту. Добавьте разные коды Aa и BB: оба ключа сохраняются. У строк этих кодов одинаковые хеши; собственный класс вправе выбирать любой согласованный хеш. Допустимы getOrDefault/put и merge. Порядок перечисления и формат вывода свободны.

Предъявите исходники и консольную демонстрацию, включая пустой вход. Объясните согласование equals/hashCode и устойчивость кода ключа во время хранения. Для готового grade.Student(String id, String name, int score) объясните, почему новая версия с другим score имеет другое полное значение, сохраняя код каталога. Ваш ключ выражает равенство именно по коду. Чтение данных и способ запуска выбирайте самостоятельно. Подготовка: Равенство записи и уникальность кода, Равенство и хеш, Карты.

Для сдачи подготовьте архив solution.zip с файлами src/main/java/Audit.java, src/main/java/CodeKey.java и src/main/java/grade/Student.java. Сохраните пакет grade у Student; остальные два файла оставьте без объявления пакета. Вспомогательные классы и методы размещайте в этих файлах.
