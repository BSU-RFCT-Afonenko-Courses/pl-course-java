Сложность: Высокий

Получите квадратную матрицу int[][], повёрнутую на 90, 180 и 270 градусов против часовой стрелки. Покажите результат каждого поворота относительно исходного состояния. Исходную матрицу не изменяйте; каждый результат поместите в новый массив.

Фиксированная исходная матрица имеет размер 3×3:

-3  0  3
 2 -1  0
 1  3 -2

Ожидаемые строки результатов:

  • 90 градусов: (3, 0, -2), (0, -1, 3), (-3, 2, 1);
  • 180 градусов: (-2, 3, 1), (0, -1, 2), (3, 0, -3);
  • 270 градусов: (1, 2, -3), (3, -1, 0), (-2, 0, 3).

Обязательные базовые имена и сигнатуры приведены в каноническом стартере задания, доступном по ссылке ниже. Реализуйте его вычислительный метод: он получает исходную матрицу и угол поворота и возвращает новый результат, сохраняя исходную матрицу. Алгоритм, вспомогательные классы и методы, способ задания данных, форму main и оформление своей демонстрации выберите самостоятельно.

Представьте исходники и команду запуска. Объясните соответствие исходной и новой координаты, покажите исходную матрицу после вычислений. На выбранном элементе поясните, как результат различает поворот против часовой стрелки и поворот в другую сторону.

Сдайте файл Study.java из src/main/java стартового проекта без объявления пакета.

Открытые примеры

Для исходной матрицы [[-3,0,3],[2,-1,0],[1,3,-2]] вызовы Study.rotate с углами 90, 180, 270 дают соответственно [[3,0,-2],[0,-1,3],[-3,2,1]], [[-2,3,1],[0,-1,2],[3,0,-3]], [[1,2,-3],[3,-1,0],[-2,0,3]]. Каждый результат — новый массив; исходная матрица остаётся [[-3,0,3],[2,-1,0],[1,3,-2]].

Последовательно вызовите повороты на 90, 180 и 270 с одним и тем же исходником [[-3,0,3],[2,-1,0],[1,3,-2]]. После всех трёх вызовов исходник содержит те же значения; требования о новых результатах сохраняются.
