Сложность: Начальный

Получите неотрицательное целое число из диапазона 0..Long.MAX_VALUE, занесите его десятичные цифры в стек и выведите их в обратном порядке. Используйте Deque/ArrayDeque как стек. Обычная запись входного числа содержит только его цифры, без начальных нулей; запись нуля — 0.

Результат — последовательность цифр без промежутков, с сохранением нулей: 120 → 021, 0 → 0. Для нуля в стеке должна оказаться одна цифра. Способ выделения цифр выберите самостоятельно.

Предъявите исходник и результат для обычного числа и нуля. Покажите использование стека и объясните, почему нули не теряются при выводе.

Вход для проверки

Для автоматической проверки предусмотрен вход стартера, принимающий число и возвращающий полученную последовательность цифр. Выполните обработку через стек; показ результата в собственной демонстрации сохраняется. Возврат строки не разрешает заменить требуемый стек готовым обращением строки. Сигнатуры входа из стартера обязательны.

Открытые примеры

Ноль в начале результата. Для числа 120 получается строка 021; ведущий ноль в ней сохраняется.

Входной ноль. Для числа 0 получается строка 0.

Сдайте Study.java без объявления пакета, сохранив объявления входа из стартера.
