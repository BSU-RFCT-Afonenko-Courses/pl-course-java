Сложность: Средний

Определите количество вхождений заданного слова в текст. При сравнении игнорируйте регистр и считайте одинаковыми буквы в каждой из пар «е/ё» и «и/й». Искомое слово непустое и состоит только из букв. Алфавит и границы слов: Данные и границы текста.

Сравнивайте целые слова. Приведение регистра и замены букв выполняются только для сравнения; исходный текст не меняется. Без слов результат равен нулю. Примеры:

Текст Искомое слово Количество
Ёлка, елка; елками елка 2
май МАЙ, маи; маий МАИ 3
x1X_xx X 2
е Ё ёж е ё 3
123! я 0
пустая строка е 0

Цифра и подчёркивание разделяют слова; xx — отдельное слово из двух букв. Заданное объединение пар букв не заменяется одной канонической нормализацией Unicode.

Представьте исходники и команду запуска. Покажите обычный пример и случай, различающий целое слово и подстроку либо варианты букв. Объясните одинаковое правило сравнения для искомого слова и слов текста, покажите сохранённый исходный текст.

Сохраните обязательные имя класса и сигнатуру операции из канонического стартера и реализуйте её для переданных данных. Алгоритм, вспомогательные методы и классы, форму main, способ задания данных и оформление демонстрации выберите самостоятельно.

Если карточка не задаёт более узкий алфавит, входные строки состоят из латинских букв A–Z/a–z, русских букв А–Я/а–я с Ё/ё, цифр 0–9, знаков препинания ASCII, пробелов, табуляций и переводов строки. Составные сочетания Unicode не допускаются. Строки не равны null; пустая строка допустима. Символ и единица длины здесь — один char.

Слово — максимальная непустая последовательность букв указанного алфавита. Цифры и все небуквенные символы разделяют слова.

Единственный файл решения — Study.java из src/main/java, без объявления пакета. Вспомогательные классы, методы и демонстрацию можно разместить в нём.

Открытые примеры

Вызов Study.count("Ёлка, елка; елками", "елка") возвращает 2: более длинное слово не учитывается. Вызов Study.count("май МАЙ, маи; маий", "МАИ") возвращает 3, игнорируя регистр и объединяя и/й только при сравнении.
