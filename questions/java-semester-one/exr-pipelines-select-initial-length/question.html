Сложность: Начальный

Через Stream API получите новый массив всех строк, которые начинаются на заданную букву и имеют длину N. Вход — ненулевой String[] без null; строки состоят из латинских букв A–Z, a–z и могут быть пустыми. Начальная буква принадлежит тому же алфавиту, N — неотрицательный int, сравнение чувствительно к регистру.

Сохраните исходный порядок и повторы, исходный массив не меняйте. Пустая строка не начинается ни с какой буквы, поэтому при N = 0 результат пуст. Для {"Ab", "ac", "Ab", "A", ""}, буквы 'A' и N = 2 результат {"Ab", "Ab"}. Пустой вход и отсутствие совпадений дают новый пустой String[].

Предъявите исходный и новый массивы. Объясните чувствительность к регистру, сохранение повторов и отсутствие совпадений при N = 0.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Открытые примеры

Для массива {"Ab", "ac", "Ab", "A", ""}, начальной буквы A и длины N = 2 результат — новый String[] с {"Ab", "Ab"}. Порядок и повтор совпадения сохраняются, исходный массив остаётся прежним.

Для массива {"", "A", ""}, той же буквы A и N = 0 результат — новый пустой String[]. Исходный массив сохраняется.

Единственный файл решения — Study.java, без объявления пакета. Решение, вспомогательные классы и методы размещайте в нём.
