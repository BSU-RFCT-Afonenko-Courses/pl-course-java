Сложность: Средний

Проверьте строку по учебному правилу формата пароля. Допустимые исходные строки и единица длины заданы в Данные и границы текста.

Строка подходит, если одновременно выполняются все требования:

  • длина — не менее 10 символов;
  • есть хотя бы одна цифра 0–9;
  • есть хотя бы одна латинская буква в верхнем регистре;
  • есть хотя бы одна латинская буква в нижнем регистре;
  • все символы — латинские буквы, цифры или _.

Верните булев результат. "Abcdefghi1" подходит. Не подходят строка длины 9, "abcdefghij1", "ABCDEFGHIJ1", строка без цифры, пустая строка и строка с пробелом. Подчёркивание разрешено, но не заменяет требуемую цифру или букву.

Проверка символов циклом и проверка шаблоном допустимы. Покажите подходящую строку и предусмотренный случай отказа; объясните, какое требование нарушено.

Сохраните обязательные имя класса и сигнатуру операции из канонического стартера и реализуйте её для переданных данных. Алгоритм, вспомогательные методы и классы, форму main, способ задания данных и оформление демонстрации выберите самостоятельно.

Если карточка не задаёт более узкий алфавит, входные строки состоят из латинских букв A–Z/a–z, русских букв А–Я/а–я с Ё/ё, цифр 0–9, знаков препинания ASCII, пробелов, табуляций и переводов строки. Составные сочетания Unicode не допускаются. Строки не равны null; пустая строка допустима. Символ и единица длины здесь — один char.

Единственный файл решения — Study.java из src/main/java, без объявления пакета. Вспомогательные классы, методы и демонстрацию можно разместить в нём.

Открытые примеры

Вызов Study.accepts("Abcdefghi1") возвращает true: длина ровно 10, есть оба латинских регистра и цифра, состав допустим. Вызов Study.accepts("Abcdefgh1") возвращает false: единственное нарушение — длина 9.
