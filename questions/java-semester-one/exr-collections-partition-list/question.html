Сложность: Средний

Получите изменяемый список Integer и значение int X. Список и его элементы должны отличаться от null. Переставьте элементы в том же объекте списка: сначала должны идти все числа, не превосходящие X, затем все числа, большие X. Размер и число вхождений каждого значения сохраняются; порядок внутри двух групп свободен. Пустой список допустим.

Работайте без методов сортировки и дополнительных массивов или коллекций. Допустимы отдельные переменные для индексов, ссылок и временно переставляемого значения. Покажите случай с обеими группами и случаи, когда одна группа пуста.

Предъявите исходник и состояние того же списка до и после перестановки. Покажите сохранение повторов и объясните работу без сортировки и дополнительных контейнеров.

Вход для проверки

Вход стартера переставляет значения в переданном объекте списка: сначала <=X, затем >X, сохраняя размер и кратности. Порядок внутри групп свободен. Ограничения на сортировку и дополнительные контейнеры распространяются на решение и его вход для проверки. Сигнатуры входа из стартера обязательны.

Открытые примеры

Две группы и повторяющееся значение. Для списка [3, 1, 4, 2, 3] и X = 2 сначала располагаются элементы мультимножества {1, 2}, затем — {3, 3, 4}. Порядок внутри каждой группы свободен. Сохраняются сам объект списка, его размер и кратность значений.

Пустой список. При X = 0 пустой список остаётся тем же пустым списком.

Сдайте Study.java без объявления пакета, сохранив объявления входа из стартера.
