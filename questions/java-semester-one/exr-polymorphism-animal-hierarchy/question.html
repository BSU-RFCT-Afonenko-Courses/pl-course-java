Сложность: Средний

Создайте иерархию Animal → Dog → Puppy. Конструктор каждого класса принимает имя типа String; имя не равно null, непустое и сохраняется после создания.

Животное умеет подавать голос; для собаки доступны бег и укус, для щенка — прыжок. Имена методов действий выберите самостоятельно. В Animal определите голос; Dog и Puppy переопределяют эту операцию с одной сигнатурой во всей иерархии. Сообщения различают вид животного и его имя; точный текст свободен.

Определите равенство по точному классу и имени, реализуйте согласованные equals, hashCode, toString. Равенство с null ложно; равные объекты имеют одинаковый хеш. toString() позволяет увидеть класс и имя, его оформление свободно. Определение равенства и связь с хешем: Обычный класс для представления значения.

Предъявите исходники и консольную демонстрацию голосов трёх видов через ссылки Animal, а также действий собаки и щенка. Сравните двух собак с одинаковым именем, собаку и щенка с одинаковым именем, объекты с разными именами и объект с null; сопоставьте равенство с хешами. Объясните, почему собака и щенок с одинаковым именем здесь не равны. Вспомогательные методы и способ запуска демонстрации выбирайте самостоятельно.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Единственный файл решения — Study.java из src/main/java, без объявления пакета. Предметные и вспомогательные классы можно определить в нём как вложенные или неоткрытые классы верхнего уровня. Методы и реализацию выбирайте самостоятельно; демонстрацию также можно разместить в этом файле.

Открытые примеры

Голоса и действия. Создайте Animal("Зверь"), Dog("Рекс") и Puppy("Луч"), вызовите голос через ссылки Animal, затем действия собаки и щенка. В сообщениях различимы вид и имя животного, действия доступны, имена после вызовов сохраняются.

Одно имя у разных классов. Два объекта Dog("Рекс") равны и имеют одинаковые хеши. Сравнение Dog("Рекс") с Puppy("Рекс") в обе стороны даёт false; сравнения с Dog("Иной") и null также ложны. В toString() собаки и щенка различимы их вид и имя.
