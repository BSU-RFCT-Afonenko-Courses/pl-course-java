Сложность: Средний

Создайте класс Vehicle с закрытыми целочисленными характеристиками passengers (число пассажиров), fuelcap (запас топлива в галлонах), mpg (мили на галлон). Число пассажиров неотрицательно; два остальных значения положительны. Открытый конструктор Vehicle(int passengers, int fuelcap, int mpg) создаёт это состояние.

Выделите в IVehicle следующие операции и реализуйте их открытыми методами Vehicle:

int getPassengers();
void setPassengers(int value);
int getFuelcap();
void setFuelcap(int value);
int getMpg();
void setMpg(int value);
int range();
double fuelNeeded(int miles);

Методы доступа читают и изменяют характеристики с сохранением ограничений. Дальность равна fuelcap * mpg; исходные данные и допустимые изменения выбираются так, чтобы произведение помещалось в int. Обработка переполнения вне условия.

fuelNeeded(int miles) возвращает double: отношение неотрицательного расстояния miles к mpg. Абсолютная погрешность не больше 1e-6. Неверные параметры конструктора, метода изменения и отрицательное расстояние отклоняются через IllegalArgumentException. Метод изменения проверяет значение до записи: после отказа все характеристики прежние. Конструктор частью интерфейса не является.

Предъявите исходники и консольную демонстрацию чтения, изменения и вычислений через IVehicle. Для Vehicle(2, 10, 25) дальность 250, топливо для 50 миль 2.0. Покажите отказ setFuelcap(0) с сохранением характеристик и дальности 250; отдельно — исключение для отрицательного расстояния. Вспомогательные методы и способ запуска свободны в пределах указанного API.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Для сдачи используйте файлы IVehicle.java и Vehicle.java из src/main/java стартового проекта. Разместите их в двух редакторах без объявления пакета. Вспомогательные классы и методы можно определить в этих файлах; демонстрацию можно разместить в одном из них, без третьего исходника.

Открытые примеры

Чтение и допустимое изменение. У Vehicle(2, 10, 25) характеристики равны (2, 10, 25), дальность — 250, расход для 50 миль — 2.0. Через интерфейс измените характеристики на (0, 12, 30): дальность станет 360, расход для 90 миль — 3.0. Абсолютная погрешность расхода не превышает 1e-6.

Отказ изменения и отрицательного расстояния. Для нового Vehicle(2, 10, 25) вызовы setFuelcap(0) и fuelNeeded(-1) вызывают IllegalArgumentException. Характеристики остаются (2, 10, 25), дальность — 250, а fuelNeeded(0) возвращает 0.0.
