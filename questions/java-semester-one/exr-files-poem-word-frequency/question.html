Прочитайте строки текстового файла; каждая строка может содержать несколько слов. Имена входного и выходного файлов и пути к ним передавайте как параметры командной строки. В каждой строке стихотворения Максима Богдановича подсчитайте частоту каждого слова из заданного списка и выведите эти слова в порядке возрастания частоты.

Выберите короткое стихотворение Максима Богдановича, находящееся в общественном достоянии, подготовьте UTF-8-файл и небольшой список слов, включая слово с нулевой частотой. Укажите название, автора и источник текста. Правила выделения слов и сравнения регистра зафиксируйте до выполнения; одинаковые частоты сохраняйте в порядке списка.

Для каждой физической строки выведите отдельный результат: слова из списка с их частотами в этой строке, включая нули. Равные частоты сохраняют порядок исходного списка. Сам список содержит различные слова; способ его передачи программе выберите и опишите. Выходной файл сохраняет порядок строк входа. Покажите строку без совпадений и строку с повтором одного слова.

Предъявите исходный текст с названием, автором и указанием источника, список слов и полученный файл. Кратко объясните выбранные правила и порядок слов с одинаковой частотой.

Вход для воспроизводимой проверки

Сохраните обязательные сигнатуры входов из стартера. Они связывают проверку с вашим решением; наблюдаются его фактические действия и результаты. Формат отчёта и диагностики выбирайте в пределах условия.

Сохраните заранее выбранные правила выделения слов и регистра. Открытый пример — один допустимый выбор; при другом законном выборе частоты сверяются по вашим объявленным правилам. Формат отчёта и способ передачи списка свободны.

Открытые примеры

В этом примере строка UTF-8-файла — Зорка Вэнэра ўзыйшла над зямлёю без конечного перевода строки, а список запросов — зорка, няма, зямлёю. При заранее объявленных правилах «слова из Unicode-букв, нижний регистр» отчёт для этой строки содержит по возрастанию частоты няма: 0, зорка: 1, зямлёю: 1; равные частоты сохраняют порядок списка. При другом допустимом заранее объявленном учёте регистра и выделении слов результат определяется этими правилами.

Для той же строки и запросов светлыя, згадкі при тех же правилах отчёт содержит светлыя: 0, згадкі: 0. Строка без совпадений не пропускается.

Сдайте Study.java без объявления пакета, сохранив объявления входа из стартера.
