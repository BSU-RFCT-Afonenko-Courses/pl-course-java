Сложность: Начальный

Создайте метод int sum(int... values), суммирующий переданные значения int. Для демонстрации используйте значения, все промежуточные суммы которых помещаются в int. Переданный массив не равен null и после вызова сохраняет свои значения.

Метод может быть статическим или экземплярным; содержащий его класс выбирайте самостоятельно. Обход индексами и enhanced-for допустимы. Вызовы sum(3, -2, 4) и sum() дают соответственно 5 и 0.

Предъявите исходники и консольную демонстрацию этих вызовов, включая сохранность массива при его передаче методу. Параметр переменной длины проверяется по исходнику. Имена остальных классов, способ запуска демонстрации и её оформление выбирайте самостоятельно.

Вход для проверки

Сохраняется уже заданный метод sum с параметром переменной длины. Технический вход стартера вызывает выбранный вами статический или экземплярный метод; содержащий класс и доступность внутреннего метода остаются свободными. Сохраните обязательные объявления входа из стартера; внутреннее устройство решения и формат демонстрации выбирайте самостоятельно в пределах условия.

Единственный файл решения — Study.java из src/main/java, без объявления пакета. Предметные и вспомогательные классы можно определить в нём как вложенные или неоткрытые классы верхнего уровня. Методы и реализацию выбирайте самостоятельно; демонстрацию также можно разместить в этом файле.

Открытые примеры

Сумма и сохранность массива. Передайте в sum массив [3, -2, 4]. Метод возвращает 5; значения массива остаются прежними.

Вызов без аргументов. Результат sum() равен 0.
