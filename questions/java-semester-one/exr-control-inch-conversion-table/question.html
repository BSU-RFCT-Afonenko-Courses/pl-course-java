Сложность: Начальный

Выведите таблицу перевода целого количества дюймов в метры для значений от 1 до 144 включительно — до 12 футов. Один фут содержит 12 дюймов, один метр — примерно 39,37 дюйма. Каждая строка содержит число дюймов и соответствующую длину в метрах; порядок строк — по возрастанию дюймов. После каждой группы из 12 строк выведите пустую строку. Точность отображения и выравнивание колонок выберите самостоятельно.

Покажите первую группу и конец таблицы. Объясните перевод единиц, выбранную точность отображения и условие вывода пустой строки.

Консольная программа выводит результат без приглашений к вводу. Числа разделяются пробельными символами; десятичный разделитель — точка.

Сдайте файл Main.java из src/main/java стартового проекта без объявления пакета.
