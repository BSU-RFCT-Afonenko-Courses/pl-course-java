Сложность: Средний

Для целых n, m, k, где n < m, определите принадлежность k каждому из интервалов (n, m], [n, m), (n, m), [n, m]. Круглая скобка исключает соответствующую границу, квадратная включает её.

Стандартный ввод содержит n m k типа int, разделённые пробельными символами. Вход корректен, условие n < m выполняется. Вывод должен содержать только четыре значения true или false в указанном порядке, разделённые пробельными символами.

Для -2 4 -2 результат — false true false true; для -2 4 4 — true false false true.

Используйте JDK 25. Точка входа — Main.main(String[] args). Способ вычисления, вспомогательные методы и разбиение программы выберите самостоятельно.

Представьте исходники и покажите обе границы, внутреннюю точку и значения снаружи интервалов. Объясните, как строгость сравнения определяет результат на границе.

Единственный файл решения — Main.java из src/main/java, без объявления пакета. Вспомогательные классы и методы можно определить в нём.

Открытые примеры

Без аргументов передайте n m k через стандартный ввод и завершите его. При -2 4 -2 получаются false true false true, при -2 4 4 — true false false true, при -2 4 0 — true true true true. Значения идут в порядке четырёх интервалов из условия. Правая граница проверяется также с разделителями TAB и LF: -2\t4\n4; это те же три числа.
