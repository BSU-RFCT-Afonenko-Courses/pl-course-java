Создайте справочную систему, которая хранит сведения в обычном текстовом файле helpfile.txt, позволяя изменять и расширять справку без изменения кода программы. Пользователь вводит название темы; программа находит эту тему в файле и отображает соответствующую информацию.

Каждый раздел начинается отдельной строкой #название-темы. Затем идут строки справочной информации; между разделами находится пустая строка. В конце строк справки нет пробелов.

Создайте класс Help, которому имя справочного файла передаётся через конструктор. Метод helpOn(String what) ищет тему, выводит сведения и возвращает признак того, что тема найдена; ошибки файлового ввода/вывода обрабатывает сам метод. Метод getSelection() получает название темы от пользователя. Программу запуска разместите в FileHelp.java.

Для самостоятельного helpfile.txt в UTF-8 создайте разделы if, switch, for, while, do, break, continue по описанному формату. Каждой теме достаточно краткого описания синтаксиса; тексты справки составляйте самостоятельно по изученным управляющим конструкциям. Отсутствие темы и ошибка чтения должны различаться в сообщении.

Названия тем уникальны, непусты и сравниваются с учётом регистра. Пустая строка завершает текст раздела; сведения внутри раздела сохраняют порядок. Для неизвестной темы helpOn возвращает false и сообщает об отсутствии темы; при ошибке чтения тоже возвращает false, но сообщение поясняет файловый отказ. При найденной теме метод печатает её текст и возвращает true. Способ завершения интерактивного ввода выберите и покажите пользователю. Общий System.in остаётся доступным для меню.

Предъявите исходники и собственный файл справки. Покажите последовательные запросы и выбранное завершение меню; объясните, как различаются отсутствие темы и файловый отказ.

Вход для воспроизводимой проверки

Сохраните обязательные сигнатуры входов из стартера. Они связывают проверку с вашим решением; наблюдаются его фактические действия и результаты. Формат отчёта и диагностики выбирайте в пределах условия.

Открытые примеры

С файлом helpfile.txt из открытого примера последовательно выбирают через getSelection() темы if и for. Оба вызова helpOn возвращают true; печатаются соответствующие разделы: сначала if (условие) оператор;, затем for (инициализация; условие; шаг) оператор;. Поток System.in остаётся открытым.

Запрос If к существующему файлу и запрос if к отсутствующему файлу дают false. Сообщения различают отсутствие темы и отказ чтения файла.

Для сдачи загрузите отдельными файлами Study.java, Help.java и FileHelp.java, без объявления пакета. Сохраните объявления входа из стартера; вспомогательные классы и методы размещайте в этих файлах. Собственный helpfile.txt используйте и предъявите при демонстрации.
