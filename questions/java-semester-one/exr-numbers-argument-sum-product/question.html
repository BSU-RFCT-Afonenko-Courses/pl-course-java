Сложность: Средний

Примите целые числа через аргументы командной строки и вычислите их сумму и произведение. Разбирайте аргументы как long; исходные данные выбираются так, чтобы все промежуточные результаты помещались в long. Для пустого набора сумма равна 0, произведение — 1. Корректная запись всех аргументов предполагается; проверять произвольный текст в этой задаче не требуется.

Выведите только два целых результата в десятичной записи: сначала сумму, затем произведение, разделив их пробельными символами. Количество пробельных символов, переносы строк и пробелы по краям вывода не фиксируются. Для аргументов 3 -2 4 результат — 5 -24, для пустого набора — 0 1. Стандартный ввод для чисел не используется.

Разместите исходники в src/main/java. Класс запуска — Main без пакета; после компиляции запускайте его командой java -cp out Main с указанными аргументами. Допустима любая форма main, которую JDK 25 поддерживает при таком запуске. Вспомогательные классы и методы выбирайте самостоятельно.

Покажите запуск с числами и без аргументов. Объясните выбор начальных значений суммы и произведения и тип промежуточных вычислений.

Консольная программа выводит результат без приглашений к вводу. Числа разделяются пробельными символами; десятичный разделитель — точка.

Сдайте файл Main.java из src/main/java стартового проекта без объявления пакета.

Открытые примеры

При запуске с аргументами 3 -2 4 программа выводит только два десятичных целых числа: 5 -24. Стандартный ввод не используется; между числами допустимы пробельные разделители, подписи не нужны.

Без аргументов сумма равна 0, произведение — 1: вывод содержит 0 1 с теми же правилами оформления и без чтения стандартного ввода.
