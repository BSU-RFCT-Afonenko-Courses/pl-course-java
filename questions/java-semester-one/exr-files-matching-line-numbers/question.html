Для вывода результатов создайте новый каталог и файл средствами класса File. Входной файл содержит текстовые строки. Найдите номера строк, совпадающих с заданной строкой. Имя файла и строка для поиска — аргументы командной строки. Выведите строки файла и номера строк, совпадающих с заданной.

Входной UTF-8-файл: строки «alpha», «beta», «alpha». Нумерация с 1, сравнение всей строки с учётом регистра. Для строки «alpha» совпадают номера 1 и 3.

Сравнивайте текст, полученный через readLine(), с аргументом поиска без изменения регистра и пробелов. Пустая строка поиска допустима и совпадает с пустыми физическими строками. Выведите все строки входа в прежнем порядке и отдельно список совпавших номеров по возрастанию; для отсутствия совпадений явно покажите пустой список. Форму двух разделов результата выберите самостоятельно и сохраните в новом UTF-8-файле. Путь результата задайте в программе или дополнительным аргументом и укажите при демонстрации. Для POSIX-оболочки пустой аргумент передаётся как '', строка с пробелом — как 'alpha beta'.

Предъявите исходник и оба файла, укажите путь результата. Покажите создание каталога и файла средствами File; объясните, чем пустая строка отличается от конца файла.

Вход для воспроизводимой проверки

Сохраните обязательные сигнатуры входов из стартера. Они связывают проверку с вашим решением; наблюдаются его фактические действия и результаты. Формат отчёта и диагностики выбирайте в пределах условия.

Открытые примеры

Вход содержит alpha\nbeta\nalpha\n, где \n — LF. Строку поиска alpha передают одним аргументом. Новый отчёт в новом каталоге сохраняет все три строки и отдельный список номеров совпадений 1, 3.

Для входа alpha\n\n alpha\n и пустой строки поиска, также переданной одним аргументом, сохраняются все три строки, включая пустую и строку с начальным пробелом. В список совпадений входит только номер 2.

Сдайте Study.java без объявления пакета, сохранив объявления входа из стартера.
