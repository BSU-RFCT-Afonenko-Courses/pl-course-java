Сложность: Начальный

Напишите программу, которая приветствует пользователя по имени из первого аргумента командной строки. Сохраните имя без изменения; последующие аргументы не учитывайте. Имя может содержать кириллицу, пробелы и эмодзи. Стандартный ввод не используется.

Команда java Main "Анна" выводит одну строку Здравствуйте, Анна!. При запуске без аргументов выведите одну строку Укажите имя.. Вывод содержит только соответствующее сообщение.

Используйте JDK 25. Точка входа — Main.main(String[] args). Вспомогательные методы и разбиение программы выберите самостоятельно.

Представьте исходники и покажите запуск с именем и без аргументов. Объясните, как программа различает эти случаи и почему имя с пробелами нужно передать одним аргументом.

Единственный файл решения — Main.java из src/main/java, без объявления пакета. Вспомогательные классы и методы можно определить в нём.

Открытые примеры

С единственным аргументом Анна программа выводит Здравствуйте, Анна!. Результат одинаков при пустом стандартном вводе и при тексте stdin не имя в нём: имя берётся из аргумента. Допустим один завершающий перевод строки LF или CRLF.

Без аргументов выводится Укажите имя. — как при пустом стандартном вводе, так и при тексте stdin не имя. Для этого сообщения также допустим один завершающий LF или CRLF.
