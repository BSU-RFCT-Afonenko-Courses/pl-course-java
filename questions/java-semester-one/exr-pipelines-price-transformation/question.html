Сложность: Начальный

Через Stream API преобразуйте список цен без налога в новый список цен с налогом. Ставка — отдельный входной параметр от 0 до 1 включительно; 0.20 означает 20%. Цены конечны и находятся в диапазоне от 0 до 1000000. Список ненулевой, без элементов null, может быть пустым.

Для каждой цены вычисляется цена × (1 + ставка), затем результат округляется до двух десятичных знаков. Выберите денежный тип и одно из правил округления к ближайшему: при точной середине округлять вверх (HALF_UP) либо к чётной последней сохраняемой цифре (HALF_EVEN). До демонстрации явно укажите выбранные представление и правило; по ним объясняются случаи округления. Сохраните порядок, повторы и исходный список. Для цены 100 и ставки 0.20 результат 120.00; нулевая цена остаётся нулевой, пустой список даёт пустой новый список.

До демонстрации назовите денежный тип и правило округления. Предъявите исходный и новый списки, случай точной середины в выбранном представлении и объяснение результата.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Денежный тип и выбранное HALF_UP либо HALF_EVEN остаются вашим выбором. Перед проверкой объявите представление и правило; точная середина и ожидания определяются именно в этом представлении. Заготовка не требует BigDecimal или дополнительного алгоритма перевода двоичных чисел в десятичные.

Открытые примеры

При заранее выбранных денежном типе и правиле HALF_UP либо HALF_EVEN для списка [100, 0, 100] и ставки 0.20 новый список содержит [120.00, 0.00, 120.00]. Порядок и повтор сохраняются, исходный список, его цены и ставка остаются прежними. Представление и правило округления сохраняют объявленный выбор решения.

Для пустого списка при ставке 1 результат — другой пустой список.
