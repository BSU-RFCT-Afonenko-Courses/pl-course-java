Сложность: Высокий

Каррированная функция принимает первый аргумент и возвращает функцию, которая принимает второй. Реализуйте лямбдами три таких операции; выбор имён и вспомогательных методов свободен.

  1. Сложение двух целых чисел: оба аргумента от -1000000 до 1000000, результат — их точная сумма. Например, применение первого аргумента 7 создаёт функцию, которая для -2 возвращает 5. Подойдут Function<Integer, Function<Integer, Integer>> или эквивалентная форма с примитивными функциональными интерфейсами.
  2. Проверка строки по регулярному выражению: первый аргумент — корректное ненулевое регулярное выражение Java, второй — ненулевая строка. Проверяется совпадение всей строки, как у String.matches. Для шаблона [A-Z]+ строка "ABC" подходит, "Ab" — нет.
  3. Разбиение строки: первый аргумент — корректное ненулевое регулярное выражение Java, второй — ненулевая строка. Результат соответствует String.split(regex, -1), включая сохранение пустых частей в конце. Для "," и "a,,b," результат {"a", "", "b", ""}.

Во всех трёх случаях сохраните полученную после первого аргумента функцию и примените её к нескольким вторым аргументам. Пустые строки допустимы; некорректные регулярные выражения за пределами входного договора.

Предъявите три лямбда-операции. Для каждой сохраните функцию после первого аргумента, покажите несколько её вызовов со вторыми аргументами и объясните данные и результат обоих этапов.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Открытые примеры

Для каждого первого аргумента сохраняют функцию и применяют её дважды. Прибавление 7 к -2 и 3 даёт 5 и 10. Проверка полного совпадения с [A-Z]+ для "ABC" и "Ab" даёт true и false. Разбиение по запятой строк "a,,b," и "x,y" даёт соответственно {"a", "", "b", ""} и {"x", "y"}.

Прибавление -1000000 к -1000000 и 1000000 даёт -2000000 и 0. Проверка с .* для "" и "A" даёт true в обоих случаях. Сохранённая функция разбиения по запятой для "" возвращает массив из одной пустой строки, а для "," — из двух пустых строк.

Единственный файл решения — Study.java, без объявления пакета. Решение, вспомогательные классы и методы размещайте в нём.
