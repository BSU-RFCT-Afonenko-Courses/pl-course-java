Сложность: Начальный

Определите собственный функциональный интерфейс: его единственный абстрактный метод принимает три double — коэффициенты a, b, c — и возвращает double. Реализуйте его лямбдой, вычисляющей дискриминант b² − 4ac. Имена интерфейса и метода свободны.

Коэффициенты конечны, модуль каждого не превышает 1000. Нулевой a допустим: в этой задаче вычисляется само выражение дискриминанта. Требуемый результат r — математическое значение выражения для переданных коэффициентов. Вычисленное конечное значение v принимается при |v − r| ≤ 1e-8 + 1e-12 · |r|. Здесь первая часть допуска ограничивает абсолютную погрешность около нуля, вторая учитывает масштаб результата.

Для (1, -3, 2), (1, 2, 1), (1, 0, 1) результаты соответственно 1, 0, -4. Покажите вызов через переменную своего интерфейса.

Предъявите собственный интерфейс и лямбду, покажите вызов через переменную интерфейса, включая допустимый нулевой a. Объясните результат и проверку его погрешности.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Открытые примеры

Метод собственного функционального интерфейса вызывают для коэффициентов (a, b, c) = (1, -3, 2). Результат v должен быть конечным; математический эталон r = 1, допуск — |v − r| ≤ 1e-8 + 1e-12 · |r|.

Для (a, b, c) = (0, -1000, 1000) тот же метод даёт конечный результат с эталоном r = 1000000 в том же смешанном допуске.

Единственный файл решения — Study.java, без объявления пакета. Решение, вспомогательные классы и методы размещайте в нём.
