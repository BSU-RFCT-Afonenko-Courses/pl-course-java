Сложность: Средний

Определите, является ли целочисленное частное положительным, если операция допустима. При нулевом делителе результат проверки считается ложным.

Вход и результат: стандартный ввод содержит два числа типа int: числитель и делитель. Выведите true, если делитель не равен нулю и целочисленное частное положительно; иначе — false. Для 7 0 результат — false без исключения, для 7 2 — true, для 1 2 — false. При пустом вводе продемонстрируйте пару 7 0.

Реализуйте условие с помощью &&, чтобы применить правило условного вычисления операндов.

Точка входа — Main.main(String[] args).

Покажите нулевой делитель и ненулевой делитель с частным, равным нулю. Объясните по исходнику, какой операнд && вычисляется первым и когда деление не выполняется.

Консольная программа выводит результат без приглашений к вводу. Числа разделяются пробельными символами; десятичный разделитель — точка.

Единственный файл решения — Main.java из src/main/java, без объявления пакета. Вспомогательные классы и методы можно определить в нём.

Открытые примеры

Без аргументов передайте 7 2 через стандартный ввод и завершите его: результат — true. В отдельном запуске ввод 7 0 даёт false без необработанного исключения деления на нуль.
