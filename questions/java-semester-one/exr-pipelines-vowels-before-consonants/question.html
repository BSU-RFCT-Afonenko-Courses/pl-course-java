Сложность: Средний

Через Stream API преобразуйте ненулевую строку из латинских букв нижнего регистра: сначала расположите все её гласные в возрастающем порядке, затем все согласные в возрастающем порядке. Гласные — a, e, i, o, u; остальные допустимые буквы считаются согласными.

Сохраните каждое вхождение буквы. Для "java" результат "aajv"; пустая строка даёт пустую. Строка только из одной группы сортируется внутри этой группы.

Предъявите исходную и полученную строки. Объясните границу двух групп, порядок букв внутри них и сохранение повторов.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Открытые примеры

Для строки "java" результат — "aajv": обе гласные a сохраняются перед согласными.

Для строки "zyb", состоящей только из согласных, результат — "byz". Буква y в этом примере относится к согласным.

Единственный файл решения — Study.java, без объявления пакета. Решение, вспомогательные классы и методы размещайте в нём.
