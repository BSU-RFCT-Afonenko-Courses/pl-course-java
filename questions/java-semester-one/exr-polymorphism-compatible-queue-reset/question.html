Сложность: Средний

Рассмотрите эволюцию интерфейса ICharQ из Очереди символов. Нужно добавить reset(), сохранив возможность компиляции класса, который реализует только put и get.

Добавьте метод по умолчанию reset(), который при вызове завершает операцию исключением UnsupportedOperationException: так клиент узнаёт, что старая реализация не поддерживает сброс. В одной новой реализации переопределите reset() настоящим сбросом. Сравните результаты и объясните различие совместимости исходного кода и поддержки операции.

Предъявите исходники старой и новой реализаций. Покажите компиляцию старого класса с расширенным интерфейсом, его отказ при сбросе и повторное заполнение новой очереди после настоящего сброса. Общий договор очередей входит в комплект.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Возвращаемый тип реального reset и вывод этого метода остаются свободными; вход проверки игнорирует его возвращаемое значение. Законный унаследованный default допускается, старая реализация по-прежнему объявляет только put/get.

Единственный файл решения — Study.java из src/main/java, без объявления пакета. Предметные и вспомогательные классы можно определить в нём как вложенные или неоткрытые классы верхнего уровня. Методы и реализацию выбирайте самостоятельно; демонстрацию также можно разместить в этом файле.

Открытые примеры

Поддерживаемый сброс. В новую очередь поместите A, B, извлеките A и вызовите reset(). Следующий get() печатает «Очередь пуста» и возвращает \0: прежний B больше не извлекается. После помещения C извлечение возвращает C. Успешные put и get молчат; вывод и возвращаемое значение самого reset() свободны.

Старая реализация. В старую очередь, реализующую только put и get, поместите A. Унаследованный reset() выбрасывает UnsupportedOperationException; после отказа get() возвращает A без сообщения. Совместимость исходного кода проверяется его компиляцией.
