Сложность: Начальный

Напишите отдельные методы пересечения и объединения двух множеств Integer. Входные множества и их элементы отличны от null; пустое множество допустимо. Каждый результат имеет самостоятельный состав; оба входа после вызова сохраняются.

Объединение содержит все различные элементы обоих входов, пересечение — только общие. Для {1, 2} и {2, 3} результаты равны {1, 2, 3} и {2}. Сравнивайте состав через равенство множеств: порядок перечисления не задан. Допустимы изменяемая копия с addAll/retainAll и явный обход с contains/add. Поддержка последующего изменения результата не требуется.

Предъявите исходники и консольную демонстрацию обычного случая, одинаковых, пустых и непересекающихся множеств. После каждого метода покажите сохранность обоих входов. Объясните, почему состав результата независим от входов. Имена вспомогательных методов и классов и способ запуска свободны в пределах файлов для сдачи. Справка: Множества и Групповые операции множеств.

Вход для проверки

Два входа стартера возвращают объединение и пересечение. Переданные множества сохраняются; последующее изменение их состава не меняет уже полученный результат. Сравнивается состав множеств, без требования порядка или изменяемости результата. Сигнатуры входа из стартера обязательны.

Открытые примеры

Общий элемент. Для A = {1, 2} и B = {2, 3} объединение равно {1, 2, 3}, пересечение — {2}. Оба входных множества сохраняются.

Пустой вход и независимые результаты. Для A = {} и B = {4} объединение равно {4}, пересечение пусто. После обоих вызовов исходные множества прежние. Последующее добавление 5 в B не меняет ранее полученные результаты.

Сдайте Study.java без объявления пакета, сохранив объявления входа из стартера.
