Сложность: Высокий

Создайте реализацию ICharQ из Очереди символов, сочетающую кольцевое хранение с увеличением массива при заполнении. Освобождённые позиции используются повторно; увеличение сохраняет FIFO-порядок.

Покажите переход индексов через конец массива, затем увеличение при расположении элементов по обе стороны этой границы. Извлечённая последовательность должна совпасть с порядком оставшихся помещённых символов.

Предъявите исходники. На своей демонстрации объясните переход через конец массива и порядок переноса оставшихся элементов при увеличении. Общий договор очередей входит в стартовый комплект.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Для сдачи используйте файлы DynQueue.java и ICharQ.java из src/main/java стартового проекта. Разместите их в двух редакторах без объявления пакета. Вспомогательные классы и методы можно определить в этих файлах; демонстрацию можно разместить в одном из них, без третьего исходника.

Открытые примеры

Переход и рост. В DynQueue(3) поместите A, B, C, извлеките A и B, затем поместите D, E, F. Следующие четыре извлечения дают C, D, E, F; операции ничего не печатают. Физическое кольцевое хранение и рост при расположении элементов по обе стороны границы массива предъявляются отдельно.

Пустая очередь и повторное заполнение. Первый get() из DynQueue(1) печатает строку «Очередь пуста» и возвращает \0. После помещения Q извлечение возвращает Q без сообщения.
