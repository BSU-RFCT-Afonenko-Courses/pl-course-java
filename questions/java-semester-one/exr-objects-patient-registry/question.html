Сложность: Средний

Создайте класс Patient со свойствами: id, фамилия, имя, отчество, адрес, телефон, номер медицинской карты, диагноз. Поля класса закрытые. Предусмотрите два конструктора с разными наборами параметров, методы чтения и изменения свойств и toString(). Отбор оформите отдельными методами для массива объектов. Строковые критерии сравнивайте целиком с учётом регистра; покажите полученную подборку, включая случай без совпадений.

Создайте массив объектов. Выведите:

  • список пациентов, имеющих данный диагноз;
  • список пациентов, номер медицинской карты которых находится в заданном интервале.

Используйте вымышленные записи с положительным целым id и непустыми строковыми свойствами; телефон хранится строкой. Нижняя граница интервала не больше верхней. Проверять неверные исходные данные не требуется. Номер карты — положительное целое; обе границы интервала включаются. Порядок результатов совпадает с исходным массивом.

Массив может быть пустым; он, его элементы и текстовые значения не равны null. Отбор сохраняет исходный массив и объекты. Если один объект встречается в массиве несколько раз, каждое подходящее вхождение остаётся в результате. Имена методов отбора, тип возвращаемой подборки и оформление вывода выбирайте самостоятельно: результат должен позволять различить записи и проверить их порядок. Для пустой подборки достаточно явного сообщения об отсутствии совпадений; его текст свободен.

Предъявите исходники и обе подборки для обычного случая и случая без совпадений. Объясните точное сравнение диагноза, включение границ и сохранение порядка и повторных вхождений.

Вход для проверки

Создайте собственный Patient и отдельные методы двух отборов. Входы стартера вызывают их на ваших реальных объектах. Диагноз сравнивается целиком с учётом регистра; диапазон номеров карт замкнутый. Обе подборки сохраняют порядок и повторы входа, не меняя массив и его объекты. Сохраните обязательные объявления входа из стартера; внутреннее устройство решения и формат демонстрации выбирайте самостоятельно в пределах условия.

Единственный файл решения — Study.java из src/main/java, без объявления пакета. Предметные и вспомогательные классы можно определить в нём как вложенные или неоткрытые классы верхнего уровня. Методы и реализацию выбирайте самостоятельно; демонстрацию также можно разместить в этом файле.

Открытые примеры

Точный диагноз и повторное вхождение. У пациента А id 41, карта 101, диагноз «Грипп»; у Б id 42, карта 102, диагноз «грипп»; у В id 43, карта 103, диагноз «Грипп». У всех фамилия «Учебный», имя «Иван», отчество «Иванович», адрес «Учебный адрес», телефон 00123. В массиве [В, А, Б, А] обе позиции А содержат одну ссылку. Отбор диагноза «Грипп» даёт [В, А, А], интервал карт [101, 102] — [А, Б, А]. После каждого вызова исходные данные сохраняются.

Пустой массив. Для пустого ненулевого Patient[] отбор диагноза «Грипп» и интервала карт [101, 102] даёт две пустые подборки.
