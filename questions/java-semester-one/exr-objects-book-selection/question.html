Сложность: Средний

Это один из двух вариантов обязательного выбора: выполните эту задачу либо «Отбор автомобилей».

Создайте класс Book со свойствами: id, название, авторы, издательство, год издания, количество страниц, цена, тип переплёта. Поля закрытые. Обязательная публичная поверхность класса Book без пакета задана в канонической заготовке: два полных конструктора для массива авторов и одного автора, методы чтения и изменения всех восьми свойств, toString() и три статических отбора, возвращающих Book[]. Тела методов в заготовке незавершены; состояние класса и всю реализацию спроектируйте самостоятельно.

Используйте положительные целые id и количество страниц, год в диапазоне 1..9999 и конечную неотрицательную цену. Список авторов содержит хотя бы одно непустое имя; название, издательство и тип переплёта также непустые. Оба полных конструктора получают значения восьми свойств. Конструктор с одной авторской строкой создаёт список из одного переданного автора. Проверять неверные исходные данные не требуется.

Создайте массив объектов и выведите:

  • книги заданного автора;
  • книги заданного издательства;
  • книги, выпущенные после заданного года.

Строковые критерии сравнивайте целиком с учётом регистра. Книга подходит автору, если заданная строка совпала с одним из имён в её списке авторов. «После» означает строгое неравенство: год, равный границе, не подходит. Порядок каждой подборки совпадает с порядком исходного массива.

Массив может быть пустым; он, его элементы и текстовые значения не равны null. Отбор сохраняет исходный массив и объекты. Каждое подходящее вхождение остаётся в результате, даже если один объект встречается в массиве несколько раз. В подборке допустимы исходные объекты или равнозначные копии с сохранением свойств, порядка и кратности записей.

Имена и сигнатуры обязательных методов сохраните по заготовке. Оформление вывода выберите самостоятельно. Результат должен позволять различить записи и проверить их порядок. Для пустой подборки достаточно явного сообщения об отсутствии совпадений; его текст свободен.

Предъявите исходники и консольную демонстрацию трёх видов отбора. Покажите две подходящие автору книги в исходном порядке, неизвестного автора с пустым результатом и исключение книги с годом, равным границе. Покажите сохранность исходных данных. Вспомогательные методы и способ запуска демонстрации выберите самостоятельно; обязательного Main нет. Автоматические 80% проверяют конструкторы, изменение свойств и каждый отбор отдельно. Инкапсуляцию, самостоятельную реализацию, содержательное представление восьми свойств в toString() и демонстрацию оценивают в ручных 20%. Точный формат toString() и защитное копирование авторов не являются обязательными.

Для сдачи используйте один файл Book.java из src/main/java стартового проекта. Разместите его в редакторе без объявления пакета. Вспомогательные классы и методы, а также демонстрацию можно разместить в этом же файле.

Открытые примеры

Автор не первый в списке. Создайте книгу B1 с id 1, названием «Массивы», авторами Анна и Борис, издательством «Свет», годом 2024, 120 страницами, ценой 10 и типом переплёта «Мягкий». У второй книги B2 id 2, название «Объекты», автор Вера, издательство «Мир», год 2025, 200 страниц, цена 15 и тип переплёта «Твёрдый». Вызов Book.author([B1, B2], "Борис") выбирает только первую книгу с id 1. Порядок и исходные данные сохраняются.

Для следующих отборов используются другие три книги:

  • B1: id 1, «Первая», авторы Ann и Bob, «Север», 2001 год, 100 страниц, цена 10, тип переплёта «Твёрдый»;
  • B2: id 2, «Вторая», автор Ann, «Юг», 2020 год, 100 страниц, цена 10, тип переплёта «Твёрдый»;
  • B3: id 3, «Третья», автор Bob, «Север», 2020 год, 100 страниц, цена 10, тип переплёта «Твёрдый».

Отбор по автору. Для массива [B1, B2, B1, B3] вызов Book.author(..., "Ann") возвращает книги с id [1, 2, 1]. Повторное вхождение первой книги остаётся в подборке; входные данные сохраняются.

Отбор по издательству. Для того же массива вызов Book.publisher(..., "Север") возвращает id [1, 1, 3] в исходном порядке, сохраняя исходные данные.

Отбор после года. Вызов Book.after(..., 2010) для массива [B1, B2, B1, B3] возвращает id [2, 3]. Исходные данные сохраняются.

Нет указанного автора. В массиве [B3] отбор по строке Ann даёт пустой массив, не изменяя книгу или исходный массив.

Регистр названия издательства. В массиве [B3] отбор по строке север даёт пустой массив: издательство книги записано как Север. Исходные данные сохраняются.

Год равен границе. Для [B3] вызов Book.after(..., 2020) даёт пустой массив, сохраняя исходные данные. Эти опубликованные примеры входят в свои проверяемые группы; отдельного балла за один пример нет.
