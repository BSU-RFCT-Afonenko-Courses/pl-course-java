Сложность: Средний

Подсчитайте и выведите число седловых точек квадратной матрицы int[][]. Позиция (i, j) является седловой точкой, если её значение минимально в строке i и максимально в столбце j. Оба условия нестрогие: равные значения также учитываются. При повторяющихся значениях подсчитывается каждая подходящая позиция.

Фиксированная исходная матрица имеет размер 3×3:

-3  0  3
 2 -1  0
 1  3 -2

Имя класса, методы, форму main, способ задания данных и оформление результата выберите самостоятельно. Алгоритм не предписан.

Покажите исходники и результат; объясните на позициях матрицы, почему должны одновременно выполняться оба условия и как учитываются равные значения.

Сдайте файл Example.java из src/main/java стартового проекта без объявления пакета.
