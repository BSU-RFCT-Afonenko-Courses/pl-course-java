Сложность: Высокий

Напишите обобщённый метод ternaryOperator, который получает условие и две функции и возвращает функцию выбора результата. Его типовые параметры и параметры метода:

<T, R> Function<T, R> ternaryOperator(
        Predicate<? super T> condition,
        Function<? super T, ? extends R> ifTrue,
        Function<? super T, ? extends R> ifFalse)

Это объявление задаёт имя метода и его типовой договор. Класс, видимость и наличие static выбирайте в своей программе. Все три переданные функции ненулевые. Ограничений на типы T и R нет; допустимые аргументы определяются переданными функциями. В частности, null допустим, если условие и выбранная ветвь его принимают. Результат выбранной ветви, включая null, передаётся вызывающему коду.

При создании результирующей функции условие и обе переданные функции не вызываются. Каждый последующий apply ровно один раз проверяет condition на переданном аргументе и ровно один раз вызывает на том же аргументе выбранную ветвь: ifTrue для true, ifFalse для false. Невыбранная ветвь не вызывается. Повторный apply выполняет выбор заново. Если условие или выбранная ветвь выбрасывает исключение времени выполнения, оно передаётся вызывающему коду без замены; дальнейшие вызовы условия и ветвей при этом прекращаются.

Покажите пример для ненулевых строк: условие проверяет пустоту, истинная ветвь возвращает 0, ложная — длину. Покажите обе ветви, повторные вызовы и случай, в котором невыбранная ветвь выбросила бы исключение. Проверьте отдельно создание функции и её вызов. Вспомогательные методы свободны.

По исходнику объясните смысл ? super T и ? extends R и место, где выполняется отложенный выбор. Форму демонстрации выберите самостоятельно.

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Открытые примеры

Условие проверяет пустоту ненулевой строки; истинная ветвь возвращает 0, ложная — длину строки. До создания результирующей функции вызовов этих трёх функций нет. Само создание их не вызывает. Последовательные применения к "", "abc", "abc" дают 0, 3, 3. При первом apply вызываются условие и истинная ветвь, при втором и третьем — условие и ложная. В каждом применении обе вызванные функции получают тот же аргумент ровно по одному разу. Всего у условия три вызова, у истинной ветви один, у ложной два.

В другом примере ненулевое условие принимает null и возвращает true, ненулевая истинная ветвь принимает null и возвращает null, а ненулевая ложная ветвь при вызове выбросила бы IllegalStateException. Создание результирующей функции снова обходится без вызовов. При одном apply(null) условие и истинная ветвь получают null ровно по одному разу; ложная ветвь не вызывается. Возвращается null, исключения нет.
