Сложность: Высокий

Поместите ICharQ и три реализации из Очереди символов в пакет qpack. Демонстрационный класс IQDemo оставьте в безымянном пакете.

Сделайте необходимые типы, конструкторы и операции доступными извне пакета. Покажите импорт, создание всех трёх очередей и вызовы через ICharQ. Представьте структуру Java-файлов и команды компиляции и запуска.

Предъявите исходники и объясните, какие объявления делают очереди доступными для IQDemo. Общий договор очередей входит в стартовый комплект.

Очереди символов

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Для сдачи подготовьте один ZIP из исходников src/main/java: в корне архива разместите IQDemo.java, а в каталоге qpack — ICharQ.java, FixedQueue.java, CircularQueue.java и DynQueue.java. Сохраните пакет qpack для четырёх файлов очередей; IQDemo.java остаётся без пакета. Вспомогательные классы и методы можно определить внутри этих файлов.

Открытые примеры

Три очереди из пакета. Для каждой из FixedQueue(2), CircularQueue(2), DynQueue(2) поместите A, B и выполните два извлечения. Каждая возвращает A, затем B; операции молчат.

Линейное место после извлечения. Для каждой очереди ёмкости 2 поместите A, B, извлеките A и попытайтесь поместить C. FixedQueue отказывает в помещении C, и её остаток — B. Кольцевая и динамическая очереди возвращают остаток B, C. После опустошения get() каждой очереди печатает «Очередь пуста» и возвращает \0.
