Сложность: Средний

Для готового текста и упорядоченного списка искомых слов выведите частоты в формате [слово1-2, слово2-3, слово3-0]. Используйте Stream API.

Текст — ненулевая строка. Слово в нём — максимальная непрерывная последовательность латинских букв A–Z и a–z; все остальные кодовые единицы служат разделителями. Регистр значим: One и one различаются. Искомые слова — ненулевые непустые строки только из этих букв; список ненулевой, может быть пустым и содержать повторы.

Записи результата следуют порядку искомых слов и сохраняют их повторы. Отсутствующему слову соответствует 0. Для текста "one, two two; One" и списка [one, two, absent, one] результат [one-1, two-2, absent-0, one-1]. Пустой текст даёт нулевые частоты всех запросов; пустой список запросов — []. Входные данные не меняются. Можно считать каждое запрошенное слово отдельным конвейером или сначала построить общий частотный словарь.

Покажите отсутствующее слово, различие регистра и повторный запрос. Объясните выделение слов, применение Stream API и сохранение порядка запросов.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Открытые примеры

Для текста "one, two two; One" и запросов [one, two, absent, one] напечатанный отчёт равен [one-1, two-2, absent-0, one-1]. Регистр различается, отсутствующее слово получает нулевую частоту, повтор запроса сохраняется. Входные данные остаются прежними.

Для пустого текста "" и запросов [One, One] отчёт равен [One-0, One-0]; входы также сохраняются. Завершающий перевод строки в обоих отчётах допустим, но не обязателен.
