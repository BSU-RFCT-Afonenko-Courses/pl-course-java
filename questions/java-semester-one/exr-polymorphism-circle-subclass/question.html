Сложность: Начальный

Объявите абстрактный TwoDShape с закрытыми полями double width, double height, String name и конструктором TwoDShape(double width, double height, String name). Предусмотрите открытые методы double getWidth(), double getHeight(), String getName() и абстрактный public double area().

Создайте подкласс Circle с открытым конструктором Circle(double radius). Допустимый радиус — конечное double в диапазоне 0 < radius <= 1e150; неверные входы проверять не требуется. Через super передайте в базовый класс ширину и высоту, равные диаметру, и имя "circle". Реализуйте площадь круга; способ вычисления выбирайте самостоятельно.

Размеры и площадь должны соответствовать одному радиусу. Для радиуса 2 ширина и высота равны 4, площадь приблизительно 12.566370614359172. Результат площади конечен. Если математическая площадь равна y = πr², возвращённое значение a удовлетворяет |a - y| <= max(1e-9, 1e-12 * |y|).

Предъявите исходники и консольную демонстрацию размеров, имени и площади. Покажите вызов area() через ссылку TwoDShape; объясните, как super устанавливает размеры базового класса. Вспомогательные методы и способ запуска демонстрации выбирайте самостоятельно.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Для сдачи используйте файлы Circle.java и TwoDShape.java из src/main/java стартового проекта. Разместите их в двух редакторах без объявления пакета. Вспомогательные классы и методы можно определить в этих файлах; демонстрацию можно разместить в одном из них, без третьего исходника.

Открытые примеры

Круг радиуса 2. Создайте Circle(2) и прочитайте размеры, имя и площадь через ссылку TwoDShape. Ширина и высота равны 4, имя — circle, площадь — приблизительно 12.566370614359172. Для математической площади y действует допуск abs(a - y) <= max(1e-9, 1e-12 * abs(y)).

Максимальный допустимый радиус. Для Circle(1e150) ширина и высота равны 2e150, имя — circle. Площадь конечна и соответствует π * 10^300 с тем же допуском; вызов выполняется через TwoDShape.
