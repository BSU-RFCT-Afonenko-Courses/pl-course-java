Реализуйте `Graph` — простой неориентированный граф. Конструктор получает число вершин `n >= 0`; вершины обозначаются индексами `0..n-1`, начальных рёбер нет. Выберите хранение, при котором добавление и удаление не требуют просмотра всех рёбер графа. Объясните стоимость операций для своего представления, например матрицы смежности или набора множеств соседей. Покажите изолированную вершину, повторное добавление, удаление и симметрию соседства.
