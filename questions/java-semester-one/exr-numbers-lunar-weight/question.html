Сложность: Начальный

Напишите программу, вычисляющую силу тяжести на Луне как 17% силы тяжести на Земле. Исходное значение — неотрицательное конечное double в ньютонах; результат также выражается в ньютонах. Масса тела при перемещении на Луну не меняется. В исходнике задайте положительный пример и покажите также нулевое значение.

Вход и результат: если стандартный ввод содержит одно число, вычислите результат для него и выведите только полученное число. Для ввода 100 результат — 17, для 0 — 0, для 7.5 — 1.275. При пустом стандартном вводе покажите два результата: для нуля и выбранного положительного примера, по одному числу в строке. Числовые аргументы командной строки не требуются.

Обозначим входное значение double через xx, а математический результат 17x/10017x/100 — через yy. Выведенное число rr должно быть конечным. Абсолютная ошибка — это |r−y||r-y|, измеренная в ньютонах. В этой задаче предел ошибки равен большему из двух значений: 1e-8 Н и 1e-12 от величины |y||y|:

|r−y|≤max⁡(10−8,10−12|y|). |r-y| \leq \max(10^{-8},\;10^{-12}|y|).

Первый предел сохраняет допуск в окрестности нуля, второй учитывает масштаб результата. Способ вычисления выберите самостоятельно. Результат можно выводить в десятичной или экспоненциальной форме с точкой; количество знаков после точки не фиксируется.

Точка входа — Main.main(String[] args).

Покажите вычисление для положительного значения и нуля, а также запуск с пустым завершённым вводом. Объясните единицы измерения, выбранные типы и соблюдение допуска при вычислении.

Единственный файл решения — Main.java из src/main/java, без объявления пакета. Вспомогательные классы и методы можно определить в нём.

Открытые примеры

В отдельных запусках без аргументов передайте в стандартный ввод 100 или 7.5, затем EOF. Программа выводит соответственно одно конечное число 17 или 1.275. Для результата y допуск равен max(1e-8, 1e-12*abs(y)); допустимы десятичная и экспоненциальная запись с точкой.

В новом процессе передайте число 0, затем EOF: нужен один конечный результат 0 с абсолютным допуском 1e-8. Числовой нуль не означает пустой ввод и не включает демонстрационный режим.
