Сложность: Начальный

Для готовой строки, отличной от null, получите HashSet различных английских слов без учёта регистра. Слово — максимальная непустая последовательность букв A–Z и a–z; остальные символы разделяют слова. В результате каждое слово записано строчными английскими буквами. Преобразование регистра должно давать один результат независимо от языка среды запуска, например при использовании Locale.ROOT.

Для one, ONE! two множество содержит one и two. Пустая строка и строка без английских букв дают пустое множество. Исходный текст сохраняется; порядок вывода множества свободен.

Предъявите исходник и состав множества. Объясните выделение английских слов и преобразование регистра, не зависящее от языка среды запуска.

Вход для проверки

Вход стартера возвращает состав различных слов: максимальные последовательности A–Z/a–z переводятся в строчные английские буквы независимо от локали. Сохраняется использование HashSet; порядок не проверяется. Сигнатуры входа из стартера обязательны.

Открытые примеры

Разный регистр одного слова. Для строки one, ONE! two состав результата равен {one, two}.

Локаль с другим правилом буквы I. При локали tr-TR строка I I, i даёт множество {i}. После примера проверяющий код восстанавливает прежнюю локаль.

Сдайте Study.java без объявления пакета, сохранив объявления входа из стартера.
