Сложность: Высокий

Получите позиционную запись неотрицательного целого числа в системе с основанием от 2 до 36. Число в десятичной записи и основание передайте аргументами командной строки. Цифры со значениями от 10 до 35 обозначаются последовательными латинскими буквами; допустим единообразный верхний или нижний регистр. Результат не содержит ведущих нулей, кроме записи самого нуля 0. Например, число 31 при основании 16 даёт 1F или 1f, при основании 2 — 11111. Диапазон исходного числа не ограничен типом long; представление должно сохранять введённое целое значение.

Выведите только позиционную запись результата. Пробельные символы перед записью и после неё, в том числе завершающий перевод строки, несущественны. Стандартный ввод для чисел не используется.

Разместите исходники в src/main/java. Класс запуска — Main без пакета; после компиляции запускайте его командой java -cp out Main с указанными аргументами. Допустима любая форма main, которую JDK 25 поддерживает при таком запуске. Вспомогательные классы и методы выбирайте самостоятельно.

Покажите нуль и число, превосходящее Long.MAX_VALUE. Объясните, как при чтении и преобразовании сохраняется исходное целое значение.

Единственный файл решения — Main.java из src/main/java, без объявления пакета. Вспомогательные классы и методы можно определить в нём.

Открытые примеры

Аргументы 31 16 дают запись 1F или 1f без ведущих нулей. Аргументы 0 36 дают ровно 0, а не пустую строку и не несколько нулей.
