Сложность: Высокий

Найдите и верните непрерывный фрагмент максимальной длины, не содержащий букв алфавита из Данные и границы текста. При равной длине выберите первый по положению в исходнике.

Пробелы, цифры и пунктуация могут входить в такой фрагмент; табуляции и переводы строки также не являются буквами. Длина считается в единицах char. Для "a12!б34?" результат — "12!". Если небуквенных символов нет, в том числе у пустого текста, результат — пустая строка.

Покажите вход и найденный фрагмент. Объясните его границы и выбор при нескольких фрагментах одинаковой длины.

Сохраните обязательные имя класса и сигнатуру операции из канонического стартера и реализуйте её для переданных данных. Алгоритм, вспомогательные методы и классы, форму main, способ задания данных и оформление демонстрации выберите самостоятельно.

Если карточка не задаёт более узкий алфавит, входные строки состоят из латинских букв A–Z/a–z, русских букв А–Я/а–я с Ё/ё, цифр 0–9, знаков препинания ASCII, пробелов, табуляций и переводов строки. Составные сочетания Unicode не допускаются. Строки не равны null; пустая строка допустима. Символ и единица длины здесь — один char.

Единственный файл решения — Study.java из src/main/java, без объявления пакета. Вспомогательные классы, методы и демонстрацию можно разместить в нём.

Открытые примеры

Для "a12!б3" метод Study.longest возвращает "12!". Для "a12!б34?" результат тот же: из двух фрагментов равной максимальной длины выбирается первый.
