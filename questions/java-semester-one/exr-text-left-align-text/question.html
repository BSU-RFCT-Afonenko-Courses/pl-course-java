Сложность: Высокий

Выровняйте заданный текст по левому краю. Вход — текст и положительная целая ширина строки width. Допустимые символы и единица длины: Данные и границы текста.

Для этой задачи слово — максимальная последовательность непробельных символов: знаки препинания остаются частью слова. Разделители — пробел, табуляция и перевод строки; их количество и расположение не сохраняются.

Длина каждого слова не превосходит width — это предусловие, делить слово на части не нужно. Размещайте слова по порядку, добавляя между ними один пробел. Если очередное слово с этим пробелом не помещается, начните новую строку. Длина каждой строки в единицах char не больше width; начальных и конечных пробелов и пустых строк нет. Верните список полученных строк: каждый элемент содержит одну строку без завершающего перевода строки. Пустой или полностью пробельный текст даёт пустой список.

Например, "one two\nthree" при width = 7 даёт строки "one two" и "three"; \n здесь обозначает перевод строки. "hello" при width = 3 не является допустимым входом.

Покажите вход, ширину и полученные строки. Объясните, когда следующее слово помещается в текущую строку, а когда переносится целиком.

Сохраните обязательные имя класса и сигнатуру операции из канонического стартера и реализуйте её для переданных данных. Алгоритм, вспомогательные методы и классы, форму main, способ задания данных и оформление демонстрации выберите самостоятельно.

Если карточка не задаёт более узкий алфавит, входные строки состоят из латинских букв A–Z/a–z, русских букв А–Я/а–я с Ё/ё, цифр 0–9, знаков препинания ASCII, пробелов, табуляций и переводов строки. Составные сочетания Unicode не допускаются. Строки не равны null; пустая строка допустима. Символ и единица длины здесь — один char.

Единственный файл решения — Study.java из src/main/java, без объявления пакета. Вспомогательные классы, методы и демонстрацию можно разместить в нём.

Открытые примеры

Вызов Study.align("one two\nthree", 7), где \n обозначает перевод строки, возвращает список ["one two", "three"]: первая строка заполняется ровно до ширины 7, исходные разделители нормализуются.

Текст " \t\n " из пробела, TAB, LF и пробела при ширине 1 даёт пустой список [].
