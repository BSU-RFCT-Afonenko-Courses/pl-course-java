Верните список полученных строк: каждый элемент содержит одну строку без завершающего перевода строки. Пустой или полностью пробельный текст даёт пустой список.

Например, `"one   two\nthree"` при `width = 7` даёт строки `"one two"` и `"three"`; `\n` здесь обозначает перевод строки. `"hello"` при `width = 3` не является допустимым входом.

Покажите вход, ширину и полученные строки. Объясните, когда следующее слово помещается в текущую строку, а когда переносится целиком.

Если карточка не задаёт более узкий алфавит, входные строки состоят из латинских букв A–Z/a–z, русских букв А–Я/а–я с Ё/ё, цифр 0–9, знаков препинания ASCII, пробелов, табуляций и переводов строки.
