Реализуйте `DynQueue<T>` с методами `void put(T value)` и `T get()` и порядком извлечения FIFO. Хранилище — массив. Когда свободного места не хватает для добавления, создавайте больший массив, сохраняя порядок оставшихся элементов.

Конструктор принимает непустой массив `T[]`. Новая очередь пуста независимо от исходного содержимого массива. После передачи клиент не использует массив напрямую; фактический тип его компонента совпадает с аргументом типа очереди. Добавляемые элементы отличны от `null`. Проверять эти предпосылки программно не требуется.

При пустой очереди `get` выводит сообщение и возвращает `null`, сохраняя состояние. Текст сообщения об отказе и коэффициент увеличения массива выбирайте самостоятельно. Другие сообщения демонстрационной программы допустимы. Для увеличения можно использовать `Arrays.copyOf`: [Arrays.copyOf для ссылочных компонентов](https://bsu-rfct-afonenko-courses.github.io/Java/handbook/arrays.html#sec-api-arrays-copy-of). Продемонстрируйте несколько увеличений вместимости, чередование добавления и извлечения и работу с двумя типами элементов. Подберите действия для нескольких увеличений с учётом выбранного способа роста. Предъявите исходник и объясните связь типов, начальную пустоту и сохранение порядка при изменении хранилища. Обобщённый вход `Study<T>` из стартера не ограничивает тип элемента сравнимыми или числовыми типами. Переданный массив имеет положительную длину и фактический тип компонента, соответствующий аргументу типа контейнера; для `Study<Number>` используется `Number[]`. Оболочка передаёт этот же массив внутреннему контейнеру, если он выделен в отдельный класс. Исходные значения ячеек не являются элементами нового контейнера. Возвращаются помещённые ссылки. Клиент после передачи не обращается к массиву напрямую и не добавляет `null`. Проверять нарушения этих предпосылок не требуется. В исходнике и объяснении сохраняется работа с `T[]` и его фактическим типом при выполнении.

Операции `put` и `get` из стартера вызывают ваш `DynQueue<T>` или наследуют его операции с доступностью для проверки. Внутренняя видимость, наследованные и эквивалентные обобщённые операции свободны.

Начальное хранилище связано с переданным массивом и его фактическим типом компонента. Добавление при нехватке места должно успешно увеличивать хранилище в пределах доступной памяти. При пустой очереди `get` сообщает об отказе, возвращает `null` и сохраняет состояние.
