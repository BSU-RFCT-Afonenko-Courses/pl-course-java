Сложность: Средний

Через Stream API постройте коллекцию частот всех кодовых единиц UTF-16 в готовой ненулевой строке. Каждая кодовая единица char учитывается отдельно, включая пробелы, переводы строк и суррогаты; дополнительные ограничения на содержимое строки отсутствуют. Пустой текст даёт пустую коллекцию.

Ключ можно представлять как Character или как целое значение кодовой единицы; частота — число её вхождений. Порядок перечисления и оформление вывода выберите самостоятельно, сохранив однозначность ключей. В "ab a" частоты: a — 2, b — 1, пробел — 1. В строке "\uD83D\uDE00" две разные кодовые единицы со значениями 55357 и 56832, каждая встречается один раз.

Подготовка: Кодовые единицы строки как источник и Источник кодовых единиц.

Покажите повтор, пробел, пустой текст и суррогатную пару. По исходнику объясните выбранную единицу подсчёта и применение Stream API.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Открытые примеры

Для строки "ab a" коллекция частот содержит ровно три ключа: a (кодовая единица 97) с частотой 2, b (98) с частотой 1 и пробел (32) с частотой 1.

Для строки, заданной Java-литералом "\uD83D\uDE00", в коллекции ровно два ключа — кодовые единицы 55357 и 56832, каждый с частотой 1.

Единственный файл решения — Study.java, без объявления пакета. Решение, вспомогательные классы и методы размещайте в нём.
