Сложность: Высокий

В круге стоят N человек с номерами от 1 до N, где 1 <= N <= 10000. Счёт начинается с человека 1: первый остаётся, второй вычёркивается. После удаления счёт продолжается со следующего оставшегося человека; после конца круга возвращается к его началу. Удаляйте каждого второго, пока не останется один. Получите порядок выбывания и номер оставшегося.

Для N = 5 выбывают 2, 4, 1, 5, остаётся 3; при N = 1 удалений нет, остаётся 1. Создайте две реализации процесса: на ArrayList и на LinkedList. Они должны давать одинаковые результаты.

Сопоставьте время на одинаковых N, выполнив несколько повторов после прогрева. Вывод результатов исключите из измерения; укажите, входит ли создание списка в измеряемый участок. Объясните стоимость удаления и поиска следующей позиции в своём алгоритме. Фиксированные времена и преимущество конкретной реализации условием не задаются.

Предъявите обе реализации и одинаковый порядок выбывания. Покажите границы измеряемого участка и объясните отдельно поиск следующей позиции и удаление элемента.

Вход для проверки

Два входа стартера запускают процесс для ArrayList и LinkedList. Каждый возвращает последовательность из N чисел: сначала N−1 удалённых в порядке выбывания, затем оставшийся. Это способ наблюдать оба результата; внутреннюю форму результата и собственную демонстрацию выберите сами. Измерения и объяснение стоимости операций сохраняются. Сигнатуры входа из стартера обязательны.

Открытые примеры

Переход через начало круга. При N = 5 обе реализации последовательно удаляют участников [2, 4, 1, 5]; остаётся участник 3. Через входы проверки каждый результат имеет вид [2, 4, 1, 5, 3].

Один участник. При N = 1 обе реализации никого не удаляют, остаётся участник 1. Входы проверки возвращают [1].

Сдайте Study.java без объявления пакета, сохранив объявления входа из стартера.
