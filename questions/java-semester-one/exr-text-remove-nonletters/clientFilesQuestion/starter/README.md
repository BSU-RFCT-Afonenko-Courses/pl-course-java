Сохраните буквы исходного текста в прежнем порядке и регистре. Алфавит и границы слов: [Данные и границы текста](https://bsu-rfct-afonenko-courses.github.io/Java/tasks/bank/text.html#sec-bank-text-input).

Удалите все остальные символы, кроме обычного пробела U+0020: исходные обычные пробелы сохраняются в соответствующих промежутках между исходными словами и по краям. Между соседними исходными словами должен остаться хотя бы один пробел; при необходимости добавьте его вместо удалённых разделителей. Дополнительные обычные пробелы допустимы в этих промежутках и по краям непустого исходного текста; их количество не фиксируется. Каждое исходное слово сохраняется целиком. Если исходный непустой текст не содержит букв, результат состоит только из обычных пробелов, число которых не меньше числа исходных обычных пробелов.

Например, `"кот,дом 2я!"` допускает результат `"кот дом я"`. Для `"кот"` допустимы `"кот"` и `" кот "`. Пустой текст остаётся пустым.

Покажите исходный текст и результат. Объясните, какие разделители удалены, какие пробелы сохранены и как предотвращено слияние слов.

Сохраните обязательные имя класса и сигнатуру операции из канонического стартера и реализуйте её для переданных данных. Алгоритм, вспомогательные методы и классы, форму `main`, способ задания данных и оформление демонстрации выберите самостоятельно.

Если карточка не задаёт более узкий алфавит, входные строки состоят из латинских букв A–Z/a–z, русских букв А–Я/а–я с Ё/ё, цифр 0–9, знаков препинания ASCII, пробелов, табуляций и переводов строки. Составные сочетания Unicode не допускаются. Строки не равны `null`; пустая строка допустима. Символ и единица длины здесь — один `char`.

Слово — максимальная непустая последовательность букв указанного алфавита. Цифры и все небуквенные символы разделяют слова.
