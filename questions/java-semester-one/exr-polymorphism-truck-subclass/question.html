Сложность: Средний

Создайте Vehicle с закрытыми целочисленными полями passengers, fuelcap, mpg: число пассажиров неотрицательно, запас топлива в галлонах и пробег в милях на галлон положительны. Предусмотрите конструктор, чтение и изменение характеристик с проверкой этих ограничений, range() для дальности и fuelNeeded(int miles) для расхода топлива типа double. Расстояние неотрицательно; произведения помещаются в int. Для базовых операций используйте открытые сигнатуры из Упражнение 17.2; дальность равна fuelcap * mpg, топливо — отношению miles к mpg с абсолютной погрешностью не больше 1e-6. Реализация самого интерфейса IVehicle в этой карточке необязательна.

Подкласс Truck добавляет закрытое поле cargocap — неотрицательную грузоподъёмность в фунтах. Реализуйте конструктор Truck(int p, int f, int m, int c), методы int getCargo() и void putCargo(int c). Покажите использование унаследованных операций без открытия базовых полей.

Неверные параметры конструктора, метода изменения или отрицательное расстояние отклоняются через IllegalArgumentException. Метод изменения проверяет значение до записи: после отказа все характеристики прежние.

Покажите обычный Vehicle(2, 10, 25): дальность 250, топливо для 50 миль 2.0; отказ изменения fuelcap на 0 сохраняет дальность 250, отрицательное расстояние вызывает исключение. Для Truck отдельно покажите отказ отрицательной грузоподъёмности.

Предъявите исходники и объясните, как подкласс использует закрытое состояние базового класса и почему отказ изменения оставляет характеристики прежними.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Для сдачи используйте файлы Truck.java и Vehicle.java из src/main/java стартового проекта. Разместите их в двух редакторах без объявления пакета. Вспомогательные классы и методы можно определить в этих файлах; демонстрацию можно разместить в одном из них, без третьего исходника.

Открытые примеры

Унаследованные характеристики. Для Vehicle(2, 10, 25) и Truck(2, 10, 25, 100) дальность равна 250, расход на 50 миль — 2.0. Грузоподъёмность грузовика равна 100. Абсолютная погрешность расхода не превышает 1e-6.

Отказ до изменения состояния. Для новых объектов с теми же характеристиками вызов изменения запаса топлива Vehicle на 0, расчёт топлива для расстояния -1 и изменение груза Truck на -1 вызывают IllegalArgumentException. Базовые характеристики остаются (2, 10, 25), дальность Vehicle — 250, грузоподъёмность Truck — 100.
