Для вывода результатов создайте новый каталог и файл средствами класса File. Из текста Java-программы удалите все виды комментариев. Результат сохраните в новый текстовый файл.

В учебном входном файле нет текстовых блоков и Unicode-escape-последовательностей; обычные строковые и символьные литералы допускаются.

Подготовьте небольшой UTF-8-файл с комментариями //, /* … */ и /** … */, а также с обычными строковыми и символьными литералами, содержащими слеши и кавычки. Последовательности, похожие на комментарии, внутри литералов удалять нельзя; перевод строки после однострочного комментария сохраняйте. Для предотвращения склейки соседних токенов замените удалённый блочный комментарий пробелом.

Вход — допустимый исходный текст Java в указанном подмножестве; незавершённые литералы и комментарии вне входного договора. Сохраните весь текст вне комментариев, включая пробелы и разделители строк. При удалении блочного комментария оставьте один ASCII-пробел на его месте и сохраните находившиеся внутри него разделители строк в исходном порядке. Поэтому int/**/x; превращается в int x;. Для строкового литерала "/* text */" содержимое остаётся прежним. Покажите экранированную кавычку и обратную косую черту внутри литерала. Пути исходного и нового файла задайте явно; оба используют UTF-8.

Открытые примеры

В открытом примере используются точные UTF-8-байты следующего текста; запись \r\n здесь обозначает CRLF:

class Demo { int/**/x; String s = "/* text */"; // хвост\r\n/**doc*/ char slash='/'; }\r\n

Новый файл в новом каталоге содержит в точности:

class Demo { int x; String s = "/* text */"; \r\n  char slash='/'; }\r\n

Пробел перед первым CRLF, два пробела перед char и оба CRLF сохраняются в приведённом результате; маркеры комментария внутри строкового литерала и символ / в символьном литерале остаются.

Для UTF-8-входа class Demo { int/**/x; }\n результат — class Demo { int x; }\n. Здесь \n — LF: пустой комментарий заменён пробелом, граница токенов и прежний LF сохранены.

Сдайте Study.java без объявления пакета, сохранив объявления входа из стартера.
