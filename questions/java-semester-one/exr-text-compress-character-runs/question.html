Сложность: Высокий

Сожмите строку, состоящую только из латинских букв A–Z/a–z. Каждую максимальную серию одинаковых соседних букв длины не менее двух замените одной такой буквой и десятичным числом повторений без ведущих нулей. Одиночную букву запишите без числа; регистр различается. Числа могут быть многозначными: aa даёт a2, двенадцать a — a12. Цифры во входной строке запрещены, поэтому результат можно однозначно распаковать. Например, hellowoooorld даёт hel2owo4rld.

Используйте JDK 25 и отдельную программу, запускаемую командой java Main. Форму точки входа выберите самостоятельно. Единственный аргумент — исходная строка целиком, включая возможную пустую строку. Вход заведомо соответствует алфавиту; стандартный ввод не используется.

Выведите только сжатый текст и завершающий перевод строки. Команда java Main "aaBBa" даёт a2B2a; java Main "" передаёт пустую строку и выводит пустую строку. Алгоритм и вспомогательные методы выберите самостоятельно.

Представьте исходники и воспроизводимые примеры: одиночную букву, последнюю серию и серию длиннее девяти символов. Объясните границу последней серии и почему длина построенного результата не задаёт позицию в исходной строке.

Единственный файл решения — Main.java из src/main/java, без объявления пакета. Вспомогательные классы и методы можно определить в нём.

Открытые примеры

Запуски с единственным аргументом aaBBa и с двенадцатью буквами a дают соответственно точный текст a2B2a и a12. Стандартный ввод не используется; после каждого результата нужен завершающий LF или CRLF.
