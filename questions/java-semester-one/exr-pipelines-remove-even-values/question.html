Сложность: Средний

В переданном ненулевом int[] оставьте нечётные элементы в исходном порядке, а оставшийся хвост заполните нулями. Отбор выполните через Stream API. Вход может быть пустым и содержать любые значения int, включая отрицательные и ноль; все повторы нечётных значений сохраняются.

Измените тот же массив, сохранив его размер. Временный массив или коллекция допустимы. {2, 3, 4, 3} превращается в {3, 3, 0, 0}, {-3, 0, -2, -1} — в {-3, -1, 0, 0}. Пустой массив остаётся пустым; массив без нечётных элементов заполняется нулями целиком.

Предъявите массив до и после вызова. Покажите сохранение его объекта и размера, объясните отбор отрицательных нечётных чисел и заполнение хвоста.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Открытые примеры

После обработки массива [2, 3, 4, 3] тот же массив содержит [3, 3, 0, 0]: оба нечётных значения сохраняются в исходном порядке, хвост заполнен нулями.

Массив [-3, 0, -2, -1] превращается в [-3, -1, 0, 0] в том же объекте массива.
