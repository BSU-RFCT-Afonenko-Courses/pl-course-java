Сложность: Средний

Сначала прочитайте целое количество n. Если оно положительно, прочитайте ровно n значений типа int и найдите наибольшее и наименьшее. При n = 1 оба результата совпадают. Нулевое или отрицательное n отклоните, не читая последовательность: пустая последовательность не имеет экстремумов.

Числа стандартного ввода разделены пробельными символами. Для положительного n гарантирован полный корректный набор чисел. Выведите Максимум: <значение>, затем Минимум: <значение>. Например, ввод 4 7 -3 0 7 даёт:

Максимум: 7
Минимум: -3

Для n <= 0 выведите Количество должно быть положительным. Приглашения к вводу не печатайте.

Точка входа — Main.main(String[] args). Способ чтения, форму цикла и вспомогательные методы выберите самостоятельно; для чтения допустим Scanner.

Представьте исходники и команды запуска. Покажите одно значение, набор только из отрицательных значений и n = 0. Объясните выбор начальных экстремумов и их связь с уже обработанными числами после выбранного шага.

Сдайте файл Main.java из src/main/java стартового проекта без объявления пакета.

Открытые примеры

Для ввода 4 7 -3 0 7, завершённого EOF, вывод имеет две строки:

Максимум: 7
Минимум: -3

Ввод 0 с последующим EOF даёт Количество должно быть положительным.
