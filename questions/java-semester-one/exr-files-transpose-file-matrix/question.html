Для вывода результатов создайте новый каталог и файл средствами класса File. Входной файл содержит квадратную матрицу: каждая строка файла задаёт одну строку матрицы. Прочитайте матрицу в двумерный массив, самостоятельно определив её размер. Выведите исходную матрицу и результат её транспонирования.

Допустимый вход — непустая квадратная матрица целых int в UTF-8: каждая физическая строка содержит одну строку матрицы, числа разделены пробелами. Размер определите из входа. Прямоугольный и повреждённый файлы находятся вне договора задачи.

Передайте программе аргументами пути входного файла, нового выходного каталога и результата в нём; укажите их при демонстрации. Вход сначала полностью прочитайте, затем сохраните исходную и транспонированную матрицы с различимыми подписями. Для строк 1 2 3, 4 5 6, 7 8 9 транспонирование даёт 1 4 7, 2 5 8, 3 6 9. Покажите также матрицу 1×1.

Выход отличается от входа: самокопирование отклоните до открытия выхода. Отсутствие входа сохраняет прежний результат. При отказе ввода-вывода сообщите причину; при отказе записи возможен частичный выход, атомарность не требуется.

Предъявите исходник, входной и выходной файлы. Покажите двумерный массив, создание каталога и файла средствами File; объясните обмен индексов и порядок чтения и записи.

Вход для воспроизводимой проверки

Сохраните обязательные сигнатуры входов из стартера. Они связывают проверку с вашим решением; наблюдаются его фактические действия и результаты. Формат отчёта и диагностики выбирайте в пределах условия.

Открытые примеры

Входной UTF-8-файл содержит матрицу из строк 1 2 3, 4 5 6, 7 8 9 с LF после каждой строки. Каталога результата и самого результата ещё нет. После файловой операции в отчёте сохранены исходная матрица и матрица из строк 1 4 7, 2 5 8, 3 6 9; подписи позволяют различить их. Входной файл сохраняется.

Для входа из единственной строки -7 без конечного перевода строки создаётся новый выход. Обе обозначенные в нём матрицы состоят из одного элемента -7.
