Сложность: Начальный

Отсортируйте переданный Integer[] по убыванию числовых значений, используя лямбда-компаратор. Массив и его элементы ненулевые; допустим весь диапазон int, пустой массив и повторы.

Результат записывается в исходный массив. Все элементы и число их повторений сохраняются. Для {2, -1, 2, 0} результат {2, 2, 0, -1}. Проверьте также крайние значения Integer.MIN_VALUE и Integer.MAX_VALUE.

Предъявите массив до и после сортировки. Объясните сравнение крайних значений int и сохранение повторов.

Вход для воспроизводимой проверки

Обязательные объявления входа заданы в стартере; сохраните их и свяжите со своим решением. Собственные классы, видимость, вспомогательные методы и алгоритмы выбирайте в пределах условия. Если предметный API уже обеспечивает этот вход, дополнительный класс не требуется.

Открытые примеры

Массив [2, -1, 2, 0] после сортировки содержит [2, 2, 0, -1] в том же объекте массива.

Массив [Integer.MIN_VALUE, 0, Integer.MAX_VALUE] становится [Integer.MAX_VALUE, 0, Integer.MIN_VALUE], также в том же объекте.

Единственный файл решения — Study.java, без объявления пакета. Решение, вспомогательные классы и методы размещайте в нём.
