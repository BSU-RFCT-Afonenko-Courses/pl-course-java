Сложность: Начальный

Напишите рекурсивный метод, печатающий строку в обратном порядке. Вход ненулевой, длиной от 0 до 256 char; каждый символ представлен одним char, суррогатных кодовых единиц нет. Пробелы и знаки препинания сохраняются. Для "Java 25!" получается "!52 avaJ"; пустая строка даёт пустой текст. Завершающий перевод строки допускается. Имя и сигнатуру метода выбирайте самостоятельно; построение обратного порядка должно использовать рекурсивные вызовы. Готовые операции обращения строки не применяются.

Предъявите исходник и вывод для непустой и пустой строки. Объясните порядок рекурсивных вызовов и условие их завершения.

Вход для проверки

Вход стартера вызывает вашу рекурсивную печать строки. Проверка снимает только вывод этого вызова, а не весь вывод Main. Все значимые символы, включая пробелы и внутренние переводы строки, сохраняются в обратном порядке; после результата разрешён один завершающий LF или CRLF. Сохраните обязательные объявления входа из стартера; внутреннее устройство решения и формат демонстрации выбирайте самостоятельно в пределах условия.

Единственный файл решения — Study.java из src/main/java, без объявления пакета. Предметные и вспомогательные классы можно определить в нём как вложенные или неоткрытые классы верхнего уровня. Методы и реализацию выбирайте самостоятельно; демонстрацию также можно разместить в этом файле.

Открытые примеры

Пробел и знак препинания. Вызов печати для строки Java 25! даёт текст !52 avaJ, сохраняя значимый пробел. После результата допускается один завершающий LF или CRLF.

Пустая строка. Ненулевая пустая строка даёт пустой текст; допускается один завершающий LF или CRLF.
