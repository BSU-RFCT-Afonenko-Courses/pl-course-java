Для вывода результатов создайте новый каталог и файл средствами класса File. Прочитайте строки текстового файла. Выберите и сохраните m последних слов в каждой из последних n строк.

Входной UTF-8-файл: строки «one two three», «four five», «six seven eight nine»; параметры m = 2, n = 2. Если слов или строк меньше, сохраняйте все доступные; разделитель слов — пробел.

Параметры m и n — неотрицательные целые числа. Слово — непустая последовательность символов между ASCII-пробелами; последовательные пробелы разделяют слова и не создают пустых слов. Пустые физические строки учитываются среди последних n строк. Сохраните порядок выбранных строк и слов, разделяя оставшиеся слова одним пробелом. При m == 0 каждая выбранная строка пуста; при n == 0 выход пуст. Для примера результат — строки four five и eight nine. Покажите также пустой файл.

Предъявите исходник, вход и результат. Покажите создание каталога и файла средствами File; объясните различие между нулевыми m и n и учёт пустой строки.

Сохраните обязательные сигнатуры входов из стартера. Они связывают проверку с вашим решением; наблюдаются его фактические действия и результаты. Формат отчёта и диагностики выбирайте в пределах условия.

Открытые примеры

В UTF-8-файле три строки: one two three, four five, six seven eight nine, с LF после каждой. При m = 2, n = 2 новый выход в новом каталоге содержит две строки: four five и eight nine.

Для того же входа при m = 0, n = 2 результат содержит ровно две пустые физические строки.
